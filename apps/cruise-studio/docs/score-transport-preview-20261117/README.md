# 共通の下部再生バーと表示設定の試聴

2026-11-17。Studio local **0.157.0-dev.1**、Viewer **0.14.0-dev.1**。`codex/score-toolbar-ui`、基準`82e4e8a7`。先行0.152〜0.156の未コミット差分を保持。正式Studio0.88.1・ファイル形式v1・ライブラリDB v3は維持する。

## 操作と保存の境界

| 対象 | 動作 |
|---|---|
| 共通の下部バー | 再生・BPM・音設定を下部へ。Viewerは範囲反復と音モードも維持。譜面クルーズの保存・Undo・履歴・小節編集操作は上部に残す。編集は停止、Viewerは一時停止／続きから再開という役割を維持する。 |
| 狭い表示 | 320/390px・横画面・幅340pxの右窓相当で1行に収める。音設定は狭い時だけ音符アイコンになり、名前はアクセシビリティ用ラベルで残す。BPMは3桁を表示できる。メニューにも音設定を残す。 |
| 曲名の選択 | メニューと同じ44pxへ曲名ボックスを拡大。 |
| フォーム一覧 | 表示項目の最後。ラベル・表示チェック・サイズスライダーを他と揃え、フォント／色アイコンは持たない。60〜160%、初期100%。保存・取消・共有プリセットへ含める。遅れて表示設定が初期化された場合も順序を保つ。 |
| フォーム拡大 | 両画面で400px以下の白いカード、中央34pxのコード名と同じ図に統一。譜面クルーズの編集は左上、閉じるは右上。Viewerは閲覧専用。 |
| 表示設定で試聴 | キャンセルの左の再生で、毎回先頭から全曲を試聴。文字サイズ・段組・色を変えてもプレビューを追従する。選択範囲・Session・履歴・音楽データを変えない独立した音声所有者を使用する。カウントイン等は現在の音設定を参照する。 |
| 試聴終了 | 保存・キャンセル・Escape・外側クリック・画面離脱で停止し、音声所有者とContextを破棄する。全停止、遅い音源読込、連続再生にも世代検証を使い、閉じた後に再生を復活させない。毎フレーム全小節のクラスを更新せず、現在の小節ノードを保持する。 |
| 音設定の名前 | 「再生設定」を操作画面・メニュー・ヘルプで「音設定」に統一。 |
| ハイライト | 両画面に透過率0〜100%。塗りの透明度を変え、枠は残す。保存・取消・プリセット共有に対応。数値を有限値へ検証・制限する。 |
| メトロノーム | クリック／ウッド／電子音にハイハットを追加。共通の端末内合成音へソフトリミッターを使い、拍音の胴を強める。ピークは約0.92以下。コード・メロディの音量や波形は変えない。音色セレクトは44px・14px。 |

表示の追加値は表示専用データへ保存する。元のProject、JSON、MIDI、音楽の拍計画、実Syncの内容は変更しない。既存の保存値は新しい値がない場合に初期値を補い、データ移行は行わない。

下部バーがスクロール前から見えること、保存・履歴の位置、編集カード／鍵盤との重なり、狭い画面と右窓、フォームの中央見出し、一覧のサイズ変更、透過率の保存と共有、設定試聴の先頭再開・段組変更・取消・全停止・読込中終了を確認した。実音源のデコードと出力、音量の独立、BPM・Space・範囲反復・スクロール、フォーム編集・Undo・Save As・履歴の既存動作も確認した。

初期のDOM移動時の参照切れを修正。旧テストの項目数・順序・不可視表示の前提を新UIに合わせ、音設定をメニューから開く試験は実際のメニュー項目を選ぶよう更新した。狭い画面で開いたメニュー越しに下部ボタンを押す試験にはしない。最終結果にこれらの旧前提の失敗は含めない。

静的265依存、12,329,711bytes、`0.157.0-dev.1-27ce392a22e7`でローカルサーバーのTCPを実際に停止。Chromeの再起動／WebKitの新規ページから模擬受信済みの譜面・音源・日本語PDF・Portを開き、同じURLへ復旧した。外部通信は遮断し、模擬Syncだけを使用した。

ユーザーの既存ブラウザ保存データは操作していない。今回は自動WebKitの確認であり、実Safari・スマホ実機・Bluetooth機器の聴感・OS実印刷は確認していない。
