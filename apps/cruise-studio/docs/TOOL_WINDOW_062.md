# Studio 0.62.0 independent tool window

Base #127 cb68742de16762f9cffc18f62fcce3ee785d6f32. No Port/shared/backend/schema changes. Synthetic localhost development authority only; production gate and writer P2 remain HOLD.

The Shell owns one optional docked tool ID. Existing tool adapters remain sole Controller/frame/audio/timer owners. The same workspace node moves into the right window; no second iframe/Controller is constructed for docking. Host workspace wrappers skip activate/deactivate for that docked owner, while the central sheet stays active. Docking an already-open tool uses Element.moveBefore to preserve iframe browsing context; if unavailable and an iframe exists, the UI refuses that transfer and asks the user to save/return to the score before opening anew. Closing and tool switching deliberately dispose the old owner. NEWS and four-app links retain their external-tab contracts.

Entry points: score toolbar icon actions and the five tool pages' former separate-tab actions. The side selector switches tools; close and Escape (in host controls) dismiss. Width is adjustable by pointer or Left/Right on the focused separator, bounded 300–600px. At <=1100px it becomes an overlay below the fixed navigation row, with at least 72px of the underlying area exposed. Desktop closing releases all reserved score width. Window scroll is independent. Native Inspector is closed when a tool window opens; reopening Inspector passes the tool leave guard and closes that window first.

Practice/Gear/My Apps requestLeave callbacks own normal save/discard/continue and crop guards. Other visible forms/dialogs conservatively block close/switch until their native save/cancel is used. Home/back pass the same guard. Tool-only form state participates in refresh and beforeunload checks. The central sheet is never destroyed/recreated; draft/history and DOM remain session-owned. Global Stop, hidden-tab and pagehide listeners remain in existing tool owners. No new audio lease or automatic audio restart is introduced.

Tests: product-page tool-window test mounts all five Pro tools, changes capo/meter, saves practice/Gear records, protects My Apps draft, verifies identical iframe on central-to-right transfer, preserves sheet DOM/draft/history, changes width by keyboard and pointer, checks 5 themes × 4 widths, Global Stop ends fake microphone tracks, confirms a tool form alone blocks refresh, pauses practice timing on switch, and blocks close/switch during image crop until native cancel/discard. Existing image, practice timer, native leave, song JSON/PDF/Pre-DTM, NEWS and Pro-link suites run separately.

Not exhaustive real-device acceptance: all timer/background combinations, Safari moveBefore support and real microphone hardware require manual validation. Chromium synthetic results are not production Account/Pro/Sync acceptance. No persistence for tool-window geometry is introduced.
