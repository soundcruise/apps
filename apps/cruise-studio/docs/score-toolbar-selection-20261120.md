# 譜面上部カードのローカル検証

2026年11月20日、譜面クルーズ `0.204.0-dev.1`（`c0de068b4`）を、ローカルサイトのChromeとWebKitで検証した。

| 操作 | 確認した結果 |
| --- | --- |
| 未選択・選択解除 | 保存など曲全体の操作は表示される。小節の操作列は選択時に現れ、譜面の余白で選択を解除すると閉じる。 |
| 1小節を選択 | 操作列に小節番号が表示され、淡い金色の「編集」でその小節が開く。第1小節では「前へ移動」が無効になる。 |
| 第1〜2小節を選択 | 選択範囲と個数が表示され、「編集」で第1・2小節が並ぶ。第1〜2小節をコピーして第3〜4小節に上書きすると、指定した2小節に反映され、元に戻す操作で復元できる。 |
| 第6小節から第2小節へ逆向きに選択 | 「編集」で譜面順の先頭4小節（第2〜5小節）が開く。 |
| 曲末の2小節を逆向きに選択 | 「後ろへ移動」が無効になる。「小節追加」で選択範囲の後ろに1小節が加わり、元に戻す操作で復元できる。 |
