# スマホ実機の検証経路

2026-11-17。ローカル候補のみ。本番・実Account・認証／Syncは変更しない。

## 現状

既存入口は `http://127.0.0.1:18874/apps/score-viewer/local/` 専用で、bootとworkerもこのoriginだけを許可する。スマホからMacのIPへ置き換えるだけでは起動しない。元のサーバーを0.0.0.0へ広げる変更は行わない。

利用者の希望はiPhone／iPad・USB接続。USB接続端末とUSB通信経路はまだ確認できていない。以下は候補であり、スマホでの成功を報告するものではない。

## iPhone／iPadをUSBで確認する場合（利用者の希望）

USBケーブルだけではiPhoneのSafariからMacの127.0.0.1を開くことはできない。このMacにはフルXcodeやiOS用port-forwardツールは入っていない。既存のMacアカウント／認証設定は変更しない。

[AppleのUSBインターネット共有手順](https://support.apple.com/ja-jp/111785)でUSB通信経路を作れるか確認する。利用者に端末接続／ロック解除／必要時の「このコンピュータを信頼」と、インターネット共有を使えるか確認を依頼済み。こちらではこれらの設定を自動変更していない。

USBにプライベートIPが割り当てられた場合、下記の静的HTTPSコピーをそのIPだけで待ち受ける案。これはUSB上のローカル閲覧への応用案で、Appleの資料が本アプリへの接続を保証するものではない。実機からそのIPへ到達できることを先に検証する。証明書の準備／端末での信頼設定は、その経路を確認してから相談する。Wi-Fi専用iPadなどインターネット共有を使えない場合は別経路を相談する。

Macのコンテンツキャッシュ／インターネット共有設定、iCloud、開発者モード、OSの信頼設定は自動変更しない。

## 静的HTTPSコピー（USBまたは同じWi-Fi）

- Viewerと必要な素材だけの静的コピーを一時ディレクトリに生成。コピー側だけに選んだHTTPS originを設定する。元のboot／SW／manifestは変更しない。
- コピーの静的manifestを再計算し、同じコードと同梱音源・PDFエンジンを使用。模擬Syncのボタン／起動処理は取り除き、サーバーにSync／Account APIは実装しない。
- Macの指定したプライベートIPだけにHTTPSサーバーをbindし、列挙した静的素材だけを返す。作業フォルダ全体、.git、設定ファイル、秘密鍵は配信しない。
- 一時的な検証用証明書と信頼設定が必要。証明書の生成／ファイルの準備と、Mac／スマホへのインストール・信頼設定は別工程。信頼設定は自動変更しない。
- オフラインと画面ロック防止まで含めるため、HTTPの警告回避だけで済ませず、信頼されたHTTPSで検証する。

この方法で進めるか相談してから、実機用のorigin・証明書・起動を用意する。公開トンネル・外部ホスティングは使用しない。

[Apple：手動インストールした証明書の信頼設定](https://support.apple.com/ja-jp/102390)、[W3C：Secure Contexts](https://www.w3.org/TR/secure-contexts/)、[W3C：Service Workers](https://www.w3.org/TR/service-workers/)。

## AndroidをUSBで確認する場合

このMacにはadbがある。端末側のUSBデバッグを利用者が許可できれば、`adb reverse tcp:18874 tcp:18874` でスマホ側の127.0.0.1から既存のloopbackサーバーを使える。LAN待受や検証用ルート証明書を追加せず、元のorigin制限を維持できる。USBの許可・端末の選択・reverse設定は回答を踏まえて行う。検証後はreverseを解除する。端末が同じWi-Fiだけの場合はHTTPSコピー方式を検討する。

## 実機で行う操作

1. 合成の独自譜面と日本語入りPDFで開始する。実ユーザーの譜面は自動コピーしない。
2. ライブラリ保存・再起動で同じ内容が開くことを確認。
3. 縦／横、タッチスクロール、フォーム拡大、表示切替、全画面を確認。
4. 再生／一時停止・テンポ・音モード・反復と、自動送り／手動送り後の復帰を確認。
5. 画面ロック防止ONで実際の消灯を確認。ホーム画面起動と画面復帰後も確認。
6. オフライン準備後に通信を切り、アプリを閉じて開き直す。保存済み独自譜面・音源・PDFが使えることを確認。
7. 通信復帰後も保存を保つことを確認し、検証用サーバー・接続設定・証明書を片付ける。

Mac上のブラウザでの画面サイズ模擬や証明書例外は、iPhone／Android実機での信頼設定・消灯・オフライン再起動の確認を代替しない。

## 実際に選んだ構成

インターネット共有はグレーアウト。同じWi-Fiが使えるとの回答により、ページ読み込みはWi-Fi、検査／操作はSafariのUSB Web InspectorまたはiPhoneミラーリングで行う。Web Inspectorは読み込み済みページを検査する役割であり、USBだけでMacのloopbackをiPhoneへ転送するものではない。[WebKitの手順](https://webkit.org/web-inspector/enabling-web-inspector/)を参照。

Mac側はWi-FiインターフェースのプライベートIPだけでHTTPSコピーを起動。検証用証明書の公開部分と合成譜面・PDFは別の限定ディレクトリからダウンロードできる。root CAは7日間有効、一時ファイルのみ。自動で信頼設定を入れず、利用者が手動で導入するか選ぶ。実機からの到達・信頼設定・ホーム画面／オフライン／消灯確認は未完了。
