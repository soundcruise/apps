# Cruise Studio UI・実機確認チェックリスト

対象: `codex/studio-ui-device`、基準 `1cad09b5eccc90c1f1ec265a0bfef40d681a0052`。UI の表示、操作、譜面入力、ローカル音声を確認する。Cloud Sync、認証、共有書き込み、Production は対象外。

## 準備

1. 専用 worktree のルートで `python3 -m http.server 18766 --bind 127.0.0.1` を実行し、同じ PC の使い捨てブラウザプロファイルで `http://127.0.0.1:18766/apps/cruise-studio/index.html` を開く。既存のブラウザプロファイル、保存データ、Account は使用しない。
2. 画面の `v0.48.0` と Home 表示、Console のエラー、アプリ内 asset の 404 がないことを確認する。テスト用の架空の曲名を使い、実データの読み込み・削除・リセットはしない。
3. 記録には端末、OS、ブラウザ版、画面幅、結果、再現操作、画面写真を残す。写真には個人情報や資格情報を含めない。

## Safari・スマートフォン

1. Mac Safari で上記 1–10 の表示、入力、音声停止を確認する。実 OS の日本語 IME、マイク権限、タブ非表示・復帰、音声出力先変更を含める。
2. iPhone Safari、Android Chrome では安全な HTTPS のテスト用 origin を用意してから、幅の狭い画面で上記 1–5、9–10 を確認する。PC の `127.0.0.1` はスマートフォンから開けない。マイクは secure context で確認する。
3. 各端末でズーム、縦横回転、タッチ時の誤操作、音声の中断・再開を記録する。自動再開がないことを確認する。

**停止条件:** 実データへの書き込み、Cloud/認証への予期しない要求、保存内容の消失、停止後の音・マイク継続を見つけた場合は、その操作を中断して再現手順を記録する。既存データを消して復旧を試みない。
