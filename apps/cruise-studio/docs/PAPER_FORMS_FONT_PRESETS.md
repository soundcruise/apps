# 1拍幅フォーム・同一プレビュー・文字プリセット — 0.119.0-dev.1

## フォームと空き枠

紙面の登録フォームを、8分/16分の細かさに依存せず「1拍（表・裏）」の幅で表示する。標準4/4では小節幅の25%から左右2pxずつを除いた幅。マス内で上下の余白を均等に保つ。小節末尾の図は小節内へ収め、裏拍や同時コードで重なる図は上下のレーンへ分ける。レーン数を揃えて隣の小節の段位置を維持する。元のコードイベントのtick/ID、フォーム素材、運指、拡大図は変更しない。

実小節のない空き枠は、既存theme.cssと同じ薄い斜線へ戻す。グレーの塗りつぶしは除去。空き枠は引き続きbar ID・音・編集・フォーカスを持たず、実小節の無効化やミュートは行わない。

## 譜面と設定の見本

差は別の曲データではなく表示経路にあった。見本は通常紙面の一時的な8分/16分指定を受け取らず、自動判定によって16分の音や伸ばしを別の見え方で描いていた。また、編集カードの解像度変更直後に紙面が再描画されず古い見た目が残る場合があった。

通常紙面と設定プレビューに同じWorking snapshot・表示オプション生成処理を使用する。フォーム、解像度、確定休符、伸ばし、実オクターブを共有。解像度切替時も紙面を更新し、編集中の入力欄とフォーカス保護は維持する。設定プレビューの行指定・ハイライトは従来どおり表示専用。

## 文字サイズのプリセット

表示設定上部で、名前を入力して「保存」。同じ名前なら更新。「保存したプリセット」を選んで「呼び出す」。不要になった設定は「削除」で除く。

保存するのは曲名・曲情報・コード・ストローク・歌詞・ドレミ・セクション名・小節番号の8種類の文字サイズだけ。コード行の高さ・全体/行別小節数・表示ON/OFF・Project・音楽データは変更しない。

新規appSettingsキーscorePaperFontPresetsV1に、名前と数値だけをこのブラウザで保存。最大20個、名前40文字。名前をHTMLとして解釈せず、数値の有限性/範囲を検証する。旧scorePaperLayoutV1/scorePaperRowsV1と他の設定キーは保持。プリセット保存/削除で容量等のエラーが起きても、既存プリセットを保持してエラーを表示する。Account同期やProject JSONへの追加は行わない。
