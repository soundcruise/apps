## フォームの直接変更

- 譜面のフォームをクリックすると、その拡大カード内で指とミュートを変更できる。別の既存フォーム編集画面へは移動しない。
- 黒丸をクリックして「人・中・薬・小・親・なし」から指を選ぶ。セーハの指は関連する同一セーハの指も更新し、端点の整合性を保つ。親・なしでは、そのセーハの指定を外す。
- 左の✓／×で弾く弦を切り替える。元の押弦位置は保持し、再度オンにすれば戻せる。元からミュートで押弦位置がない弦をオンにする場合は開放弦となる（ボタンの説明にも表示）。1本以上は弾く弦を残す。
- 「譜面に反映」で対象コードだけに一括反映。キャンセル・Escape・カード外クリックでは、未反映の変更を破棄する。曲の保存は上部の「保存」で行う。
- フレットの移動・コード名や楽器条件の変更は行わない。通常の詳細フォーム編集は編集カードから使える。

保存経路は既存の`localChordForms.adopt`とEditing Sessionを利用する。任意の使用弦指定を受け取れるようにし、指だけの変更でミュート指定が消えないようにした。素材はimmutableのまま、対象eventIdのbindingだけを更新。拍の途中のコードも、そのIDで取り扱う。Undo/Redo・明示保存・JSON・再読込の既存契約を維持する。

紙面は`playedStrings`からミュート表示を導く。投影だけで×を描き、保持した元の押弦位置は書き換えない。再生も同じ使用弦を使う。既存のフォーム確認・MIDI資格判定は緩めない。

## 再生設定

上部の「再生設定」に次を集約した。

| 設定 | 動作 |
|---|---|
| コードの音量 | ギターとミュート音。0〜100%、初期100% |
| メロディの音量 | ピアノ／音の試聴。0〜100%、初期100% |
| メトロノーム・カウントインの音量 | 共通の0〜100%、初期100% |
| カウントイン | 再生前の1小節。範囲ループは初回だけ |
| メトロノーム | 曲の再生中に毎拍鳴らす |

音量は再生中にも滑らかに反映し、再生を開始し直さない。0%でも時間・プレイヘッドは進む。チェック2種は次の再生から反映。各設定はブラウザ内のAppSettingであり、Project・曲JSON・MIDIには入らない。破損した設定原文は上書きせず、保存失敗時は画面内だけに適用して通知する。

既存Audio Coordinatorの同一AudioContext内に3系統のGainNodeを設け、発音時刻・ストロークの強弱・カウント／ループ周期を維持する。ゲイン変更に15msの平滑化を使い、停止時には既存のコンテキスト終了経路で解放する。設定表示中も再生は継続。画面離脱では音声と設定カードを閉じ、非表示の編集欄へフォーカスを戻さない。
