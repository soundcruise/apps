## 今回の動作

- 運指文字を18px、フレット番号を19pxへ拡大。丸の大きさや押弦位置は変えず、番号を下げて運指との間隔を確保。白黒図と詳細設定へ適用し、音名/度数表示の文字詰めは原本のまま維持。
- 任意コードの適用後、作成ボタンの下へ赤字で「構成音を表示中です。指板をクリックして押さえ方を決めてください。」を表示。ダイアトニック選択で解除。保存済みフォームの確認状態をこの案内で変更しない。
- 「コード本棚を開く」で、その本棚まで編集カード内をスクロールする。古いProject/小節への遅延スクロールは拒否する。
- ダイアトニックカードの上に「コード進行を再生」。編集中の1／2小節のコードだけを、BPMとコード位置に従ってアコギ音で試聴。既存の「再生」はコード×ストローク＋メロディ、「全曲再生」は全曲のまま。
- 白黒の選択フォーム、各本棚コード図、詳細設定に単独コードの試聴ボタンを設置。試聴でコードを入力・変更・保存しない。
- 編集カードの「×」を右上へ移動。右窓への配置ボタンと重ならないようヘッダーに領域を確保。
- メロディ再生は鍵盤を開いている間だけ表示。閉じた状態では背景/枠/内側余白をなくし、入力オクターブの上下/C4だけをドレミ行の直下に残す。直接入力は引き続き可能。

## 再生の境界

`chord-audition.mjs` はProjectの読取り投影のみ。フォームがあれば、明示された非ミュート弦のチューニング＋カポ＋フレットから音を作る。フォームのない基本コードはコード名から参考音を作る。解釈できないコードや楽器条件は案内し、別の和音へ黙って置き換えない。

コード進行の持続は試聴用の計算で、未指定の音価やフォームの確認状態をProjectへ書き戻さない。新しい音源・音声ランタイム・保存先は追加せず、既存のサンプル音源とAudio coordinatorを使用する。入力未確定・競合・保存中・古い選択は拒否。編集、移動、Undo/Redo、ページ非表示、全停止で試聴を止める。

## ローカルの確認手順

保存が必要なテストdraftを保存してから http://127.0.0.1:18874/ を再読込みする。既存サーバーは停止していない。

1. 小節のコード行▼を開き、指の文字・フレット番号・単独試聴ボタンを確認する。
2. 2小節にしてコードを入力し、「コード進行を再生」→停止を確認する。既存再生との違いも確認する。
3. 詳細設定の任意コード作成→適用で赤い案内を確認し、指板を編集する。試聴とUndo/Redoを確認する。
4. 本棚を開き、そこへスクロールすることと、本の中の各コードの試聴で譜面が変わらないことを確認する。
5. 鍵盤を閉じた時はC4の上下だけ、開いた時はメロディ再生も表示されることを確認する。
6. 浮動カードと右窓、1／2小節、保存・再読込みを確認する。実ユーザーのProjectは使わない。
