# フォーム行基準の中央配置・ハイライト解除 — 0.124.0-dev.1

## フォームの配置

前版は、フォーム行内のflex要素（sheet-form-lane）が高さの確保と図の絶対位置の基準を兼ねていた。外側の行が共有トラックへ伸びた時にも、図は内側の要素の高さ/余白を基準に置かれる構造だった。paddingやfont-sizeだけを調整する対応をやめ、laneは高さの確保だけに使う。図の位置はフォーム行全体を基準にする。複数段の図も、行の上下余白を除いた範囲に配置する。

旧版9abfbfbeのpaper-forms/paper-layoutを隔離ブラウザへ差し替え、laneに18pxの下余白を加える合成条件で、白い画像の上余白5.56px/下余白23.57pxという上寄りを再現した。これは利用者環境の余白発生源を断定する試験ではなく、内側要素の余白に図の配置が左右される問題の再現である。新版は同じ条件でも中央に揃う。

従来のspan外枠の検査に加え、SVG内の実際の白背景cc-fb-mono-panelと、フォーム行の罫線内側を比較する。通常の60/100/140%、複数段、余白のあるlane、2倍密度、画面拡大、見本と実譜面を確認する。フォーム素材・指・音程・登録イベントの位置は変更しない。

## 表示設定

- 項目名を「フォーム」へ変更。既存の表示チェックを同じ見出し行に残し、見本/実譜面/上部チェックが同期して図と行を表示/非表示にすることを確認する。
- 余白や見出し、設定カードの背景など、編集項目以外をクリックしたらactiveSetting自体を解除する。画像・線のハイライト、左側の強調、調整中の説明を消す。リサイズ後も復活しない。設定値は保持する。
- 見本の行をクリックした時は、行の選択枠と個別配置設定だけを表示する。行全体への塗りは追加しない。余白クリックで行の選択と個別設定も閉じる。
- 表裏の線は未設定時の初期値と「おすすめに戻す」を点線に変更。明示的に保存された実線/破線などは保持する。UI・印刷・見本・実譜面で同じ既定値を使う。

Project/素材/履歴/保存契約、既存プリセット、他アプリ、共有CSS、正式版0.88.1、本番認証/Account/Sync/配信設定を維持する。ローカル18874候補だけを更新し、公開・main mergeは行わない。過去の高速初回ストローク・OS印刷/聴感・実アカウント本棚接続のHOLDは継承する。

## 検証

関連Node403件、通しChrome122件/WebKit122件、実18874＋模擬本棚18件PASS、skipなし。選択行を保持したままプリセット操作でもハイライトを消す最終調整は、Chrome/WebKit各5件でも確認。外部/本番認証/Cloud通信0、page errorなし。

白背景の実寸と行の罫線内側を比較し、内側laneの下余白・倍率・重なる図に影響されないことを検査。旧版差し替えで同じ試験が失敗し、新版で通ることも確認した。診断用の旧版差し替えファイルは試験後に除去し、開発サーバー/ユーザーのProjectへ旧コードを戻していない。フォーム表示チェック、実譜面/見本/上部チェックの同期、余白/見出しクリック、リサイズ後のハイライト非復活、点線の初期値/明示的な実線の互換、Project/履歴不変を確認。
