# 2分音符・2小節の入力単位・拍ロックとコード入力

2026-11-17。Studio local **0.160.0-dev.1**、Viewer0.16.0-dev.1。基準82e4e8a7、codex/score-toolbar-ui。既存の未コミット差分を保持。

## 操作

- 行の入力単位は **8 → 16 → 4 → 全 → 2 → 8**。「全」は小節全体、2分は4/4の半小節。
- 2小節表示では、行のボタンで表示中の両小節へ同じ単位を適用する。曲末で表示が1小節だけの場合はその小節だけ。コード・ストローク・歌詞・ドレミは独立。
- 拍別の8／16ロックは、行の単位を変更しても保持する。ユーザー承認どおり、全・2分では固定した拍を優先し、その前後をまとめる。2分は小節中央の境界も保持する。
- 例：2拍目16分固定＋全＝「1拍目のマス」「2拍目の16分4マス」「3〜4拍目のマス」。ロック解除時は前後が再びまとまる。固定した拍のボタンから解除できる。行のボタン自体にロックは付けない。
- 各コードマスの▼を削除。マスを選んで「コード」横の▼から開く。2小節目のマスでもその位置を対象にし、入力画面は両小節のコード行の直下、ストローク行の手前に横幅を使って表示する。もう一度▼で閉じる。

変更は編集画面の入力単位・配置。切替だけで既存のイベント、音・歌詞の位置／長さ／ID、音楽Project、履歴、保存形式を変更しない。マスが大きくなった場合は既存の細かな入力の保護処理を利用する。ロック値と行単位はSession内の表示設定で、曲ファイルへ追加保存しない。

2小節目の歌詞編集中に左の行ボタンを押した場合、現在入力中の小節を使って確定し、表示している両小節の単位を変える。1小節目へ誤って入力を渡さない。IME・不正入力は保護。古いコード開閉ボタンが別のSessionや現在のマスを変更しないよう、接続状態と所有者を検証する。
