# コード入力画面の配色・文字サイズ

2026-11-17。Studio local 0.160.1-dev.1。基準82e4e8a7、codex/score-toolbar-ui。先行未コミット差分を保持。

コード横の▼から開くローカルのコード入力画面のみを調整。暗色テーマは濃い青灰色の背景、明るい青灰色のボタン、白寄りの文字。明色テーマは温かい灰白色の背景、白いカード、濃い文字。選択中のコードは落ち着いたゴールドの塗り・濃い文字・枠で明示し、現在のコード名との一致を表示専用属性へ反映する。コードクルーズ本体のCSS・ルールは変更しない。

コード名はclamp(10px,1.6cqi,14px)からclamp(12px,1.8cqi,16px)へ。確認したPCカード幅では12.64px相当から14.22px、上限16px。ローマ数字は補助情報として小さく保つ。スマホ幅はボタンに56pxの最小幅を与え、長い7thコード名を切らずカード内で横スクロールする。

ダーク・チャコール・グレー・ライトの4テーマをChromeで撮影確認。コード名の最小コントラスト比は暗色8.73、明色9.95。ローマ数字も4.5以上。390px・4和音の長いコード名に文字あふれなし。Chrome／WebKitの既存コード入力・Undo・IME・2小節・配置回帰12件成功。新しい機械的なスタイル専用テストは追加していない。実Safari・スマホ実機は未確認。
