# 再生のメトロノーム・滑らかな追従・フォーム編集

ローカル候補 **0.137.0-dev.1**。基準HEAD `7f69b433`、作業ブランチ `codex/score-toolbar-ui`。先行0.132〜0.136の未コミット差分を保持。正式製品版は0.88.1のまま。コミット・push・本番配信・公開HTML・実Account/Sync・他アプリへの変更は行っていない。

## 操作

- 上部の「▶ 再生」で、表示されている対象を再生。「■ 停止」で止める。Spaceの既存動作も維持。
- 「メトロノーム」をオンにすると、譜面の再生中に毎拍鳴る。小節頭は高い音。カウントインとは独立し、範囲ループでも毎周鳴る。設定はこのブラウザに保存され、初期値はオフ。
- 再生中は、現在小節を画面中央付近へ少しずつ追従。BPMから移動の速さを決める。手動スクロールは現在の小節中は優先し、次の小節から追従を再開する。カウントイン中・フォーム拡大中・停止後には追従しない。曲頭・末尾ではスクロール可能な範囲内に留まる。
- 譜面のフォームをクリックし、拡大カードの「編集」を押すと、そのコードの既存フォーム編集へ移動する。指の変更は既存のUndo／Redo・保存・JSONへ反映。同じ小節の別コードには反映しない。
- 拡大カード外のクリックでも閉じる。カード内の余白やフォームをクリックしただけでは閉じない。閉じる／Escapeも使える。
- ストローク空欄は、拍の表・コード変更位置で補う。明示した休符・ミュート・伸ばしを優先する。再生が作った警告は停止時に解除し、別の入力・保存エラーは消さない。

## 実装上の整合性

`score-playback.mjs`の既存コード進行用`fillBlankStrums`を譜面／編集カードの再生にも利用。補完は読み取り専用の再生投影であり、ストローク素材や曲JSONを変更しない。和音のない補完拍では無用な警告や音を生成しない。

メトロノームは既存Audio Coordinator、同一AudioContext・時計・キャンセル経路を使う。`click`イベントを曲のspanへ加え、カウントインは初回のみ、その後は曲とクリックを同時にループする。Project・schema2・MIDIへのクリック書込みはない。設定キーは`cruiseStudio.appSettings.scoreMetronome`。破損した設定原文は保持し、保存失敗時は画面内だけに適用する。

フォームの入口はコードのeventIdを保持し、`owner-chord-panel.mjs`の既存`localChordForms.adopt`へ接続。同じ小節に複数コードがある場合や、拍内の保護されたコードでも対象を取り違えない。古いSession／構造チケットを拒否する。素材の上書きや別のフォーム保存経路は作っていない。
