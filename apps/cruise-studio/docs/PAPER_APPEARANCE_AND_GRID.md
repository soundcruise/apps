# 文字・罫線・選択行の表示設定 — 0.123.0-dev.1

## 操作

- フォーム行の文字ベースラインの影響を除去し、上下の余白を4pxずつへ縮小。単独図/複数段の図の外側の余白を揃える。おすすめのフォームサイズは100%に戻す。おすすめ操作でフォームの表示状態自体は維持する。
- 「カスタム設定」タブを削除。表示設定を開いた時は行未選択とし、見本の行をクリックした時だけ、その行の枠数/使用小節数を左側へ表示。見本の行以外の余白や見出しをクリックすると選択と個別設定を閉じる。サイズ/書体などの操作では選択行を維持する。
- 9種類の文字項目に、見出し/表示チェック/Aa書体アイコン/色スウォッチを横並びで配置。その下はサイズスライダーと数値。書体は標準・ゴシック・明朝・丸ゴシック・等幅の端末内フォントから選ぶ。フォントをダウンロードしない。
- 小節線・拍線・表裏の線に、色、0〜4pxの太さ、実線/破線/点線を追加。表裏の設定は細かい16分線にも適用する。未変更の場合は従来の16分線の薄さを保持する。
- 変更は実譜面/見本/印刷へ反映する。キャンセル/Escで戻し、保存で確定。書体・色・罫線・表示状態は全体プリセットにも含める。ドレミの既存オクターブ色は、色を指定するまでは保持し、色指定時は選んだ単色に統一する。

## 保存と既存データ

既存のローカル表示設定にappearance（text/lines/visibility）を追加する。既知の書体ID、6桁の16進色、有限かつ範囲内の太さ、既知の線種、booleanだけを採用し、不明なCSS/URLは適用しない。設定/プリセットの取得値は深いコピーで、既存データを参照経由で変更できない。旧設定・旧文字プリセットを引き続き読める。

表示設定内のコード/フォーム/ストローク/歌詞/ドレミのチェックは、Projectを書き換えないローカル上書きとして保持する。上部カードのチェックと一致させる。上書きがない従来データでは元のProject表示設定を維持する。グリッド表示/解像度の既存操作は、その経路を維持し、他の表示フラグを変更しない。ローカル上書き使用後も、グリッド操作のチェック値と実表示が一致することを確認する。

Project schema、音符/コード/フォーム素材、再生順、Undo/Redo、Repository保存契約は変更しない。実Account/Sync・本番認証・共通CSS・公開HTML/配信設定・正式版0.88.1は不変。main merge/本番公開は行わない。
