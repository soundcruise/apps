# 譜面ビューワー UI・音同期・PDF保存の見直し

2026-11-17、Studio local **0.154.0-dev.1** / Viewer **0.11.0-dev.1**。基準 `82e4e8a7`、作業ブランチ `codex/score-toolbar-ui`。先行 0.152 / 0.153 の未コミット差分を保持。本番・公開HTML・実Account・認証／Sync設定・Workers・他の既存アプリは変更しない。コミット／pushなし。

## 操作と外観

- 書き出しの「おすすめ」表記を外し、別名保存、次の書き出し、完了後のビューワー移動、再生をStudioの落ち着いたゴールドに統一。
- 本棚からフォルダ／ファイル表示に変更。PCは左のフォルダ一覧と右のファイル一覧、スマホはフォルダから内容へ移動し、上部の階層表示で戻る。未指定は未分類。通常は閲覧だけ、編集時に名前・場所・複製・削除・フォルダ管理を出す。PCは編集時にファイルをフォルダへドラッグ移動できる。
- 原本バイト、既存entries／folders、CAS更新と独立した複製を維持。DB v3・ファイルv1は変更せず、既存データを移行・一括書換えしない。
- ライブラリの入口をゴールドの枠で強調。配置・拡縮は44pxの高さを揃える。
- メニューをファイル／表示／配置・拡縮／再生に整理。小画面では上部をメニュー・ライブラリ・集中表示、下部をテンポ・中央の再生・繰り返し・音モードの1行に収める。隠れた操作はメニューからも使用可能。
- 音設定と送り設定は右上の同じ位置。1小節選択のハイライトは表示時計が次の小節へ進むと消える。複数選択と繰り返し中の範囲は維持する。

## 一定の音ずれの原因と対策

ユーザー回答は「最初からほぼ一定のずれ」。発音予約時計は変えず、装置出力時刻に対応した表示時計を維持して調査した。

実際に同梱のギターMP3をブラウザでデコードすると、ピークの1%を超えるまで約46〜53msの先頭部分があった。サンプル読込時に低振幅の接頭部だけ除き、1msの安全余白を残す。音程・弦順・ストローク内の発音間隔・楽譜のtick planは変更しない。修正後、40／60／67の各MIDIサンプルは1%閾値まで約3〜6ms、ブラウザ試験では12ms未満を確認。

機器固有の遅延が残る場合に備え、音設定の折り畳み「音と棒の同期」に「棒を遅らせる」0〜1000msを追加。表示だけに適用し、音声予約・テンポ・音量・楽譜は変えない。「自動に戻す」は追加補正0へ戻す。端末・譜面版別の再生設定に保存する。

自動試験は音源波形と時計・予約の契約を検証する。実スピーカーから聞こえる音との主観的な一致、Bluetooth・スマホ実機の体感は未確認。手動補正が必要な場合、音設定で調整する。

## PDF保存と印刷

独自譜面の「PDFとして保存」は印刷ダイアログを使わずPDFをダウンロードする。譜面クルーズとビューワーで同じ閲覧専用出力を利用する。元の曲、表示中の位置、ライブラリには変更を加えない。フォームはブラウザのSVG描画で事前に画像化し、途中で切れないようにする。非演奏枠は控えめな斜線を維持する。

ページ内に必要な行だけを描画し、見出しと次の行を可能な範囲で同ページに収める。フォームの寸法は先にまとめて測り、各画像置換のたびに曲全体のレイアウト計算を繰り返さない。変換時だけローカル同梱html2canvasを読み込み、外部サービス・CDNへ送信しない。20MiB以内のPDFを生成する。

**生成PDFは画像ベース**で、文字選択・検索はできない。文字／ベクターを使うブラウザ印刷は別の「印刷」から利用できる。一般PDFの保存は原本バイトをそのままダウンロードし、印刷はPDF.jsで描画した安全な画像を使用する。OSの実印刷操作は未確認。

## 検証

Node **2,337成功、失敗0、既存スキップ1**。Python模擬ストア **9成功**。Chrome／WebKitの通常回帰 **168成功**、サーバーを実際に停止したオフライン起動 **3成功**、計 **171成功・失敗0**。模擬Syncで受信した原本を使用し、Chromeはブラウザを再起動、WebKitは新規ページで譜面・音源・日本語PDF・Portを検証。サーバーはfinallyで同URLへ復旧した。実Syncへは接続していない。

PDFは両エンジンで直接ダウンロード・再読込・独立した印刷入口を確認。128小節はA4 **6ページ**、約2.9MB（Chrome）／4.1MB（WebKit）、保存から最終ページ読込まで約3.2秒／4.4秒。Popplerでも構文・A4・ページ数・非暗号化・JavaScript／フォームなしを確認し、先頭／最終ページを描画して目視した。フォームの欠け、見出しの重なり、斜線の欠落を修正済み。画像PDFの斜線もピクセルで回帰確認する。

最終ログ（ローカル）: `/private/tmp/viewer154-complete.log`、`/private/tmp/viewer154-cold.log`、`/private/tmp/viewer154-node-final.log`。再試行や親ケースの数を重複加算しない。

波形回帰は同等の発音計画を同じ48kHzのPCMフレームへ丸めて比較する。無音除去で先頭の急な波形が現れ、浮動小数の演算順による1フレームの丸め差が旧比較に現れたためで、許容誤差は緩めていない。修正後の最大差は両エンジン約3e-8、相対誤差約6e-8。スクロール解除の試験も、実際のwheelイベント配送を待ってからメニューを開くようにし、メニューへ移した操作はその入口から実行する。Safariでは既存のlocalhostタブでフォルダ／ファイルの2ペイン、整理済みメニュー、音同期設定を確認。既存の保存データは変更せず、再生停止状態で終了した。
