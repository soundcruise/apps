# 表示設定の保存・キャンセルとフォーム調整 — 0.120.0-dev.1

## UI

- ヘッダーは「キャンセル」「保存」。編集中のプレビューを見ながら試し、保存で確定する。キャンセル/Escは表示・行配置・プリセットの変更を元へ戻す。保存できない場合は閉じず、調整内容を保持してエラーを表示する。
- 文字サイズプリセットはページ最下部の枠なし1行。選択すると呼出し、名前を入力して「プリセットに保存」。選択済みの場合だけ削除を表示。プリセットの追加/更新/削除も最後の「保存」で確定し、キャンセル対象になる。
- 「フォームの大きさ」スライダーを追加。60～140%、5%刻み、100%は1拍幅。文字サイズとは別の表示設定。重なった図は上下へ分ける。
- 単独の図が上に寄る原因を修正。別の拍の重なりで行が高くなっても、重なっていない図は上下の中央に置く。衝突しているグループだけ複数段で配置し、各小節の段の高さを揃える。
- コード行の高さの独立設定を廃止。コードの文字サイズから高さを決め、旧chordHeight値は表示には使わない。

## おすすめの初期値

1行2小節、フォーム100%、曲名26px、曲情報11px、コード18px、ストローク15px、歌詞14px、ドレミ14px、セクション名13px、小節番号9px。小さいコード図を読みやすくすること、歌詞とドレミを同じ大きさにすること、情報行を控えめにすることを優先した。

既存の保存設定は読込み時に保持。「おすすめに戻す」でこの初期値と現在のProjectの自動行配置を試せる。キャンセルで元へ戻せる。別Projectの行指定は変更しない。

## 保存の整合性

以前の3キー（scorePaperLayoutV1 / scorePaperRowsV1 / scorePaperFontPresetsV1）は読取り移行元として残す。新しいscorePaperDisplayV2に、表示設定・全Project用の行指定・文字サイズプリセットを1つの値として保存する。既存storage.setAppSettingを使うため、localStorageの1回の書込みで確定し、途中までの保存を作らない。アプリ設定の他キーは保持。Project/Repository/素材/音楽データの保存形式は変更しない。

設定を開いている間はメモリ上の下書きだけを更新し、キャンセルで保存領域へ書かずに戻す。保存前に設定の版を比較し、別画面の更新があれば上書きを拒否する。容量エラーでも元の保存内容を保持する。旧プリセットの名前と文字サイズも引き継ぐ。プリセットは従来どおり8種類の文字サイズだけを持ち、フォームサイズや行配置を呼出しで上書きしない。
