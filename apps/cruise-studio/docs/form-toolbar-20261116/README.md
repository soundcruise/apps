# ローカル候補 0.141.0-dev.1 — フォーム編集と上部カード

基準 `7f69b433` / `codex/score-toolbar-ui`。先行の未commit差分を保持。Studio正式版0.88.1、Chord正式版1.23.0は変更せず、Chordのローカル候補は1.24.0-dev.1。公開HTML・配信・Worker・Account/Sync・shared・他のアプリに変更なし。commit / pushなし。既存ローカルサーバー http://127.0.0.1:18874/ を再利用。

## 変更

- 高いフレットのフォームにも0フレット側の領域を用意し、×を押弦位置に重ねない。×は実際にクリックでき、開放弦へ復帰できる。空き位置をクリックすると、その弦の押弦位置を追加・変更する。縮小図のクリック座標は描画倍率と左側cropを補正する。
- 白黒フォームの下に「クリックすると運指が変更できます。」を表示。再生ボタンをコード名の右へ移動。
- 譜面から開く拡大図の編集でも空き位置へ音を追加できる。Session/adopt・playedStrings・不変素材・Undo/Redo・Save/JSONを維持し、バレーは同じChord resolverで再計算する。既存の固定フォームを開いただけでは再作成しない。
- CAGED選択は切替前の横位置を保持して新しい図を描画後、目的位置へネイティブのsmooth scrollで移動する。通常の指変更では従来どおり位置を保持する。`prefers-reduced-motion: reduce`ではアニメーションを省略する。新しいコード編集の初期表示は運指。
- FM7 / E型 / 通常の0〜3Fを含む範囲では、4弦3F・3弦2F・2弦1F・1弦開放、5/6弦ミュートを頻出フォームとして採用する。**定義はChordのgetFormに1か所だけ置く**。Studioのrecommendも同じ定義を使う。
- 「FM7のフォーム」の詳細で正式なE型へ切り替え、頻出型へ戻せる。正式型の音・指は従来どおり。ハイフレットや他の根音には例外を適用しない。説明は`formNotice`に持ち、演奏上の危険を表す`warning`とは分ける。正式型を保存して再読み込み/Undo/Redoしても、実際の登録内容に合う案内を表示する。
- コードカードと開いたメロディカードの右上に「閉じる」。小節編集画面と内容は保持する。狭い画面ではメロディ再生を次行へ置き、閉じるボタンを右上に保つ。
- 「表示」の末尾に「詳細設定」を置き、従来の表示設定へ接続。譜面スタイルの入口は非表示。ズーム3ボタンはメニュー外へ出し、表示ボタンの横に常時表示。
- 曲メニューは「保存」「曲の設定」「ファイル」の3群。上書き保存/名前をつけて保存、曲情報/キー・カポ/基本ストローク/セクション、新しい曲/JSON読込・書出/印刷を配置。上書き保存は元の保存コマンドを呼び、保存済みや書込み不可では無効かつ薄い表示。

## 境界

今回ユーザーが明示的に許可したChord側のローカル変更は、共通フォーム定義・Exploreの型切替・指板の座標/ミュート描画・開発版番号、およびその試験だけ。Studioの作業中依存境界テストはこの正確なファイル一覧だけ例外として確認し、正式なrelease-boundary関数自体は緩めていない。公開キャッシュ番号や公開入口・認証設定は更新していない。
