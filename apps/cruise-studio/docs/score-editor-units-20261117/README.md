# 編集画面の入力単位・色・全画面と五線譜への対応案

2026-11-17。Studio local 0.159.0-dev.1 / Viewer 0.16.0-dev.1。基準82e4e8a7、codex/score-toolbar-ui。先行未コミット差分を保持。本番・実アカウント・認証／Sync設定を変更せず、コミット・pushなし。

## 実装

- 編集カードにも詳細表示設定のハイライト色・透過率・棒の色を適用。コード選択・ドレミ選択も同じ色を使用する。
- Viewerの全画面は紙面幅794pxを基準に中央配置、通常の縦譜面は元の段組で描画。閲覧用の表示変更のみで、保存された配置設定を上書きしない。横1行モードは維持する。スマホは画面幅まで縮む。通常モードへ戻すと設定された配置へ戻る。
- Viewer上部の表示を右寄せ、配置セレクトの見える「配置」ラベルを削除。アクセシビリティ名は維持する。
- 編集カードのまとめて入力と上部一括8／16切替、行折り畳みを廃止。コードの▼は左下、拍の入力単位は右下。
- 各行のボタンで **8 → 16 → 4 → 全 → 8**。全は小節全体1マス。コード／ストローク／歌詞／ドレミが独立。行の変更時はその行の拍別指定を解除して揃える。行ボタンにロック表示は付けない。4分の行でも拍別ボタンから8／16／行追従へ変更できる。
- 入力単位は編集Session内の表示状態。切替だけで既存イベントの位置・長さ・ID、歌詞、音、Undo履歴を変えない。粗いマスに複数イベントが入る場合は既存の保護処理を使う。入力不正・IME中は切替しない。古いカードのボタンから別の曲を操作しないよう所有者も検証する。
- 両画面と設定ダイアログのボタン・入力へホバー説明を補完。既存の具体的な説明を優先し、表示・音設定・保存・履歴等は機能説明を追加。編集「？」にも新しい入力単位を記載する。

## 五線譜の現状

調査対象は `js/core/melody-notation.js`、`melody-commands.js`、Common Music変換、`js/modules/sheet-cruise/melody-editor.js`。今回、五線譜エンジンと保存形式は変更しない。

現行には、メロディの長さの自動設定、空き時間を休符として描画、小節内で長い音を分割した際のタイ、五線上を選んで開始位置・音価・休符を修正するInspectorがある。空き時間は「未確認」と明示し、休符として確定する操作がある。五線変換は4/4を前提とし、小節またぎのタイ・三連符・五線譜の印刷は未対応。コード譜のPDF保存と五線譜のPDF保存は別であり、現在は前者のみ。

## シンプルなUIを保つ対応案（未実装）

| 対象 | 自動判断の基本 | 必要な時だけ行う修正 |
|---|---|---|
| メロディの長さ・休符 | 入力マスと既存のdurationから音価を作る。音が途切れる空き時間は休符として表示。既存の手動指定を優先する。 | 五線の音／休符をクリックし「長さ」「休符にする／音符にする」。未確認の箇所だけ控えめに表示する。 |
| タイ | 1つの長い音を拍や小節の境界で分割する時に自動でタイを付ける。明示した「伸ばす」を継続の根拠にする。 | 五線上で「次の同じ音へつなぐ／切る」。同じ音が続くだけでは再発音か保持か判別できないため、自動で結合しない。 |
| コードとストローク | コードは次の変更まで継続。ストロークは発音・伸ばし・明示休符を使用。コード名の空欄を休符にしない。継承した基本ストロークも尊重する。 | コード譜は通常そのまま。伴奏のリズム表記が必要な時だけ、五線側で音価・休符・保持を修正する。 |
| 歌詞 | メロディの開始位置に合わせる。伸ばした音では歌詞を保持し、必要なら歌詞の延長線を自動表示する。 | 歌詞のずれだけドラッグ等で直す。歌詞行自体にタイや休符ボタンは不要。 |

優先順は次の通り。

1. **自動変換＋修正の入口整理**：既存Inspectorの技術的なtick入力を通常は隠し、「長さ」「休符」「伸ばす」にまとめる。変換しただけでは元データを書き換えず、修正はUndo可能にする。
2. **小節をまたぐタイ**：音を小節ごとに保持しつつ継続関係を管理する。再生で二重に鳴らさず、MIDI・保存往復でも意味を保つ。保存形式への影響を先に検証する。
3. **3/4・6/8と弱起**：弾き語りで使う拍子と歌い出しに対応する。6/8は3つずつのまとまりを自動で組む。「全」は全音符を無理に置く意味ではなく、その小節の長さ全体を表す。
4. **五線譜のPDF／印刷**：コード・メロディ・歌詞をまとめて出力し、行・ページ境界のタイや歌詞を検証する。
5. **必要時に三連符**：スウィングや3連の曲用。通常画面に常設せず、五線の選択音から追加する。自動判定が曖昧なら提案に留める。

付点・連桁・臨時記号・コードと歌詞の横位置は表示側で自動処理する。複雑な多声部、オーケストラ編成、高度な装飾音は当面対象外。元の入力画面へ五線編集用ボタンを増やす必要はない。
