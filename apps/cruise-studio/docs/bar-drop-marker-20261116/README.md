## 操作

選択後に小節をドラッグすると、移動先の小節の左端に青い縦線を表示。「第4小節の前へ」のラベルを添え、複数選択なら「（2小節）」のように対象数を示す。移動元は薄く表示し、ドロップするまでは曲の内容を変更しない。

従来の「ドロップした実小節の前へ挿入する」動作を維持。選択範囲内、同じ位置への移動、斜線の空き枠、譜面外では挿入線を出さない。同じ並びでも移動先セクションへ所属を変える場合は有効。未選択からのドラッグは、従来どおり範囲選択。

線は紙面の拡大率に影響されない太さで表示し、スクロールに追従する。表示範囲と上部カードの境界で縦線を切り、ラベルも画面内に収める。ドロップ、Escape、dragend、画面/Project切替、描画更新、ウィンドウのblur/resizeで消す。外側からのデータには反応せず、保存中/未確定入力/古いSessionへのドロップは実行しない。

移動と単一Undo、移動先セクションへの所属、コード・フォーム・歌詞・メロディの保持は既存のmoveBarsを使う。表示状態だけのDOM/フレームを追加し、保存schemaや再生データは変更しない。印刷には挿入線を出さず、移動元も通常の濃さに戻す。
