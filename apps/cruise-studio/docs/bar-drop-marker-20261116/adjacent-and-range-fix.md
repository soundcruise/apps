# 隣への移動と余白からの範囲選択 — 0.135.0-dev.1

基準7f69b433。先行0.132〜0.134差分を保持し、今回も未commit・未push。正式0.88.1、本番配信・公開HTML・認証・実Account/Sync・他アプリは無変更。

## 隣の小節へ移動

0.134では、全てのドロップを対象小節の「前へ」としていた。そのため1小節目を右隣の2小節目へドラッグしても元の並びとなり、無効位置として線が出なかった。

対象小節の左半分では前へ、右半分では後ろへ挿入する。青い線を左右の境界へ切り替え、「第2小節の後へ」のように表示する。表示とドロップ確定は同じ位置判定を使う。複数小節・曲末・行末・セクション末にも対応する。

既存moveBarsに任意のafterIdを追加。beforeId、方向ボタンの既存仕様を保ち、曖昧な複数アンカー、自己参照、不正な非連続範囲は原子的に拒否する。セクション末への後挿入は、その対象小節のセクションへ所属する。後続小節をbeforeIdに流用して別セクションへ入ることを避ける。保存schemaへの追加はない。

## 余白からの範囲選択

外側からのドラッグで最初に届いたpointermoveだけを始点にしていたため、速い操作では途中の小節を飛ばして狭い範囲になることがあった。また選択済みの小節があると、余白からすぐに選び直せなかった。

- 譜面左右の作業余白から開始でき、既存の選択もドラッグで選び直せる。小節上からのドラッグは従来どおり移動として扱う。
- ポインターの移動線分と小節の矩形を調べ、最初に横切った実小節から最後に横切った実小節までを選ぶ。左→右、右→左、余白→余白の速い操作でも途中を取りこぼさない。
- 選択中は上部カードの高さを一時的に固定し、操作列の変化で譜面がずれることを防ぐ。終了時に戻す。
- マウスを離した直後のclickで、作った範囲を余白クリックとして解除しない。通常の余白クリックによる選択解除は維持する。
- ツールバー、編集カード、リンク、入力欄、フォーム図、楽曲メタデータ、タッチ操作は範囲開始から除外。IME/未確定入力/保存・競合/古いフレームの保護を維持する。
