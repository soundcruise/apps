# 譜面上部カードとコード入力の整理 — 0.142.0-dev.1

基準97b3a0ba、作業ブランチcodex/score-toolbar-ui。Studioローカル候補だけを更新。正式0.88.1、公開HTML、認証、実Account/Sync、Worker、他アプリ、sharedは変更しない。未コミット・未push。

## 操作

- 曲メニューの最上段は「新しい曲を作成」。保存・曲設定・ファイルのその他の項目順は維持。
- 曲メニューと表示をカード右上に横並び。ズームは操作案内と同じフッターの右端へ移し、右に24px、狭い画面は16pxの余白を確保。
- コード各マスの左上に▼。入力済み・空欄いずれも、その小節・拍の入力を開く。元のコード行の開閉ボタンも残す。細かな既存イベントを含む読み取り専用マスは保護する。
- 不正入力・IME・古いDOM・異なるSessionへの書込みを防ぐ。2小節表示、右側ウィンドウ、Enterによる▼起動を検証。コード変更は既存のSession入力・フォーム採用経路を使用。
- 「鳴らす弦・フォームの管理」を削除。フォーム図で指・ミュートを変更できるため独立した弦チェック欄を重複して置かない。保存済みのplayedStringsと内部configureStrings APIは保持する。以前の「フォーム解除」の独立ボタンもこの欄とともに削除。
- 白いフォームカードはコード文字自体を中央へ。試聴は独立した右側の控えめなアイコン。長いコード名も左右の余白を対称に確保。
- 回帰確認で検出した、表示設定取消後のUndo無効表示を修正。表示設定変更・close通知で履歴ボタンも再評価する。
- 狭い右側2小節エディタではメロディの閉じる・オクターブ操作・試聴を別行にして重なりを防止。
