# 譜面の余白・表示設定 — 0.116.0-dev.1

2026-11-12。PR #274の6d57c5ceをbaseとした独立ローカル候補。前の記録は [SCORE_SELECTION_CHECKPOINT.md](SCORE_SELECTION_CHECKPOINT.md)。

## 変更

- フォームは列の左右へ2pxずつ空け、各フォーム用の段で上下中央へ配置。段の上下に6pxの余白を確保し、図の白い外枠が上の罫線へ接しないようにした。同時位置の複数フォームは既存どおり縦に分ける。
- コード行は初期24pxへ縮小。番号帯も18pxへ縮め、選択時の「編集する」がコードへ重ならないコンパクトな配置にする。大きな文字を選んだ場合は文字が切れない最小高さを確保。
- 上の表示チェックへ「小節番号」「パート名」を追加。小節番号を画面で隠しても編集ボタン用の最小帯は維持し、印刷では帯ごと省く。パート名を隠すと見出しの領域も省く。
- コードクリック時の拡大図を440pxから300pxへ縮小。紙面用SVGの固定ベースラインを、黒丸の中心を基準にした配置へ修正。編集カード内の原本コードクルーズ指板や運指指定は変更しない。
- 編集カードを閉じた状態で左右キーにより前後小節を選択。Enterで編集開始。コピー/貼り付けボタンからも次の小節選択へ進める。編集中のセル/音、入力欄、フォーム拡大、表示設定、IME/競合/保存中、別Workspaceでは紙面移動を受け付けない。曲端では小節を増やさない。Shift+左右は今回追加しない。

## 見本付き「表示設定」

上部カードの「表示設定」で、合成4小節の譜面を見ながら次を変更できる。

- 1行の小節数：自動、1/2/3/4小節。自動だけが従来の歌詞なしセクションの倍詰めを使う。明示指定では表示内容によらず指定小節数で改行する。
- コード行の高さ。
- 曲名、曲情報、コード、ストローク、歌詞、ドレミ、パート名、小節番号の文字サイズ。
- 「初期値に戻す」で表示設定のみを戻す。見本と実譜面・印刷へ反映し、実Projectのデータや履歴は変更しない。

見本はcreateSampleProjectから独立して作り、合成コード/歌詞/音/リズムを明示したもの。実ユーザーのProject/本棚を使わない。見本の指板と譜面には実際と同じ描画処理を使用する。見本内の図や見出しは操作対象にしない。

新しい表示設定は既存のcruiseStudio.appSettings内のscorePaperLayoutV1へ保存。このローカルorigin・ブラウザの全Projectへ共通で、Project JSON/Session/draft/Undoには追加しない。既存の小節ルーペ配置やオクターブ色など他のアプリ設定を保持する。数値の型/範囲を正規化し、不正な保存値をCSSへ渡さない。

遅延読込みされるローカル描画機能の準備完了時に専用の接続関数でコントロールを設置し、初期化順で「表示設定」が欠落しないようにした。実18874でもこの順序を検証済み。

## ユーザー確認

保存したいローカルdraftを保存して http://127.0.0.1:18874/ を再読込みする。

1. 「フォーム」をON。図の中央配置と余白、コード行の高さ、コードクリック時の小さい拡大図と指文字を確認。
2. 小節の余白をクリック→左右キーで選択→Enterで編集。編集中は従来のセル/音移動が維持されることを確認。
3. 「小節番号」「パート名」のチェックを切り替え、印刷用表示も確認。
4. 「表示設定」を開き、小節数・コード行の高さ・文字サイズを見本で調整。閉じて実譜面を確認し、再読込み後も設定が残ることを確認。
