## 今回の操作

- 斜線の枠は **空き枠** と呼ぶ。1回クリックで選択、再クリックまたは上部の「編集」で「編集画面を起動／キャンセル」の2択を開く。キャンセルでは曲・履歴とも無変更。「編集画面を起動」を選ぶと、その時点で通常の空の小節へ復帰し、既存の編集カードを開く。コード・歌詞・メロディのイベントは空で、通常の小節数・再生時間に含む。1回のUndoで空き枠へ戻る。
- 譜面の余白、未入力のマス、カードの操作がない余白をクリックすると小節・範囲・空き枠・セクションの選択を解除する。操作ボタン・メニュー・入力欄・編集中のカードはそれぞれの操作を保持する。不正入力・IME中は従来どおり対象変更を拒否する。小節番号の帯は小節を選ぶ入口として維持する。
- 何も選択していない状態からドラッグで連続小節を選べる。Shift＋クリック／矢印の範囲選択も維持する。すでに小節を選択している状態のドラッグは、従来の小節移動に使う。ドラッグ中は上部の選択操作列を一時的にフローから外し、譜面が動いて選択位置がずれることを防ぐ。
- 複数小節を選んで上部の「再生」、または譜面上でSpaceを押すと、選択範囲だけを繰り返す。「停止」またはSpaceで停止し、範囲選択は保持する。選択解除後の再生は曲の先頭から、単一小節の選択時は従来どおりその小節から曲末まで。空き枠は範囲に含まず、実小節だけを対象にする。
- フォーム拡大はフォーム図の表示枠だけで起動する。コード名は通常の小節選択／再クリック編集となり、フォーム拡大を起動しない。
- キー・カポ画面では、両モードとも変更後の登録フォームを自動で再作成する。追加の確認チェックは撤去した。既存の推奨フォーム生成と評価を使い、手動フォームも置き換わる。変更は曲・メロディ・楽器条件・フォームをまとめて1回のUndoで戻せる。「実音を保つ」は実音を維持し、「曲全体を移調」は選んだキーの差だけコードとメロディを移調する。

前回候補の「入力の確定まで空き枠を維持」「フォーム再作成の確認チェック」は、今回の明示指示で上記へ変更した。保存拡張 `scoreLayoutV1` 自体は変更しない。

## ループの時間・停止契約

`buildRangeLoopPlan` は既存の全曲計画から連続範囲だけを読み取る。範囲頭の継続コードは既存の和声解決を使い、Projectの小節やイベントを複製・変更しない。周回周期は小節の音楽時間とし、発音準備用の0.03秒を周回ごとに加算しない。

音声は既存Coordinatorの1つのcontext／leaseを使い、1秒先までの既存ストリーミング予約を周期ごとに繰り返す。再生位置の棒は同じ音声時計から範囲内へ折り返す。終了した音源ノードは従来どおり切断し、周回数分のイベントを配列へ追加しない。停止・対象変更・画面離脱・割込み時は既存のepoch／Session検証とcleanupを使う。範囲ループでも他の音声資源を奪わず、停止失敗を自動で迂回しない。
