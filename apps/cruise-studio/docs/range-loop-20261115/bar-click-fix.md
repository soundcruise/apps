# 小節全体のクリック — 0.130.1-dev.1

ユーザーの補足に合わせ、小節の内側は未入力の行・マス・内側の余白も含めて、クリックで選択、選択済みの小節の再クリックで編集を開く。選択解除は小節の外側の余白だけに限定した。フォーム図の表示枠は従来どおり拡大を開く。フォーム行でも図のない部分は通常の小節選択となる。

コード名のカーソルを `zoom-in` から通常の矢印へ修正した。フォーム図の拡大カーソルは維持する。入力不正・IMEなどの既存ガード、空き枠の確認、範囲選択とループは維持する。

Chrome／WebKitの操作試験14件、Chromeの関連回帰6件が成功（親テストを含む）。各表示行の空白、番号非表示、フォーム図だけの拡大、外側での選択解除、入力データ／履歴を変えないことを確認した。実機Safariは今回操作していない。

ローカル候補だけを更新。正式0.88.1、本番配信・公開HTML・実Account/Syncは無変更。コミット・pushなし。0.130.0時点の[記録](README.md)にある「未入力のマスで解除」は今回の補足で変更した。
