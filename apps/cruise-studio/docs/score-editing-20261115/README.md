# 譜面の編集操作 — ローカル候補 0.129.0-dev.1

基準 `6a95c4b8`、作業ブランチ `codex/score-toolbar-ui`。先行する未コミットの上部カード整理を保持し、承認された5点を実装した。正式版は0.88.1。本番配信・公開HTML・認証・実Account/Sync・他アプリ・共有CSSは変更していない。コミット・pushは未実施。

## 操作

1. **斜線枠**：クリックで選択、もう一度クリックまたは「編集」で空の入力画面を開く。開閉・キャンセルでは曲を変更しない。コード／ストローク／歌詞／ドレミを入力して確定すると通常の小節になり、編集カードへ移る。貼り付けでも復帰する。空のままの枠は小節番号・演奏時間・再生・MIDIに含まない。
2. **曲の設定**：「曲メニュー → 曲の設定」に曲情報／セクションの2タブ。曲名・アーティスト・BPM、セクションの名前・順序・追加・削除をまとめて適用／キャンセルできる。セクションの小節数は表示のみとし、増減は譜面の小節操作で行う。キー・カポ／基本ストロークは専用の小画面に分けた。
3. **コードフォーム**：曲メニューの独立した入口を隠し、コード編集カード内の「鳴らす弦・フォームの管理」へ構成音・度数、使用弦、フォーム解除を集約。フォーム選択・運指変更・本棚は既存のコード編集カードを使う。楽器のフレット上限はキー・カポ画面で確認できる。
4. **複数小節**：Shift＋クリック、Shift＋矢印で連続選択。コピー／貼り付け、複製、移動、削除に対応する。通常の貼り付けは表示されている枠の順に上書きし、斜線枠も順に復帰する。「挿入して貼り付け」は既存の小節を後ろへ送る。削除は「枠を残して削除」「詰めて削除」。複数操作も1回のUndoで戻る。⌘／Ctrl＋C・Vは譜面選択時に使え、テキスト入力・IME・編集中のマスとは競合しない。
5. **譜面を直接クリック**：曲名、アーティスト、BPM、キー／カポ、基本ストローク、セクション名から編集できる。セクション名の横の「▶ ここから」で再生する。コード名／フォームのクリックは、従来のフォーム拡大を維持する。

クリップボードは同じ編集Session内のメモリだけに保持する。別曲・再読込後に流用しない。入力不正、保存中、競合、古い操作対象では変更しない。キー／カポやフレット上限が登録フォームへ影響する場合は、フォームを再作成する確認を必要とする。「実音を保つ」はコードとメロディの音を変更せず、「移調」はコード・メロディ・ドレミの基準音を一緒に変更する。

## 保存と表示の分離

実際の音楽小節は既存の `bars` のみ。斜線枠は任意のバージョン付き拡張 `extensions.scoreLayoutV1` に保存する。`holes` はセクションと次の実小節を参照し、`fills` は行の空き枠を入力で埋めた分だけ消費枠数を調整する。行の個別設定の変更を優先し、異なる設定へ古い埋め数を適用しない。

削除した小節の位置IDを空き枠へ引き継ぎ、復帰時にも保持する。これにより行の配置設定が失われない。内容やイベントは削除され、貼り付けでは新しいイベントIDを発行する。セクション／小節の移動・削除時は空き枠の参照を整え、不正な参照や未知の拡張バージョンは読み込み時に拒否する。ほかの拡張データは保持する。配置・フォントの既存ブラウザ設定は引き続きProjectとは別に保存する。斜線枠を起点とする行ルールはプリセット内に枠位置も保存し、呼び出し後の復帰でも保持する。

音声／MIDIへ無音の偽小節を挿入しないため、従来の小節数、和声の継続、再生時間の計算とぶつからない。全実小節を削除した場合も空き枠から再開できる。
