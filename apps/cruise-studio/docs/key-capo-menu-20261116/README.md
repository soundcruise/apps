## 操作

曲メニューの一段目に「曲情報」「キー・カポ」「基本ストローク」「セクション」を置く。「曲の設定」を経由する2タブと、その中から別の設定を開くボタンを撤去。新規作成後は同じ「曲情報」を開き、曲名を全選択する。曲情報とセクションは、それぞれ適用/キャンセルで確定する独立した画面。

半音上下だけの旧「移調」サブメニューは非表示とし、移調はキー・カポへ集約。旧ハンドラは互換のため残す。キー・カポのフレット上限は「楽器の詳細」に収めた。メニューから開いた設定を閉じると、曲メニュー見出しへフォーカスを戻す。

## カポの意味

変更前が原曲キーC・PlayキーC・カポ0の場合:

| 変更方法 | 原曲キー（実音） | Playキー | カポ |
|---|---|---|---|
| 実音を保つ | C | B♭ | 2 |
| 曲全体を移調 | D | C | 2 |

「曲全体を移調」では、カポの上下量をそのまま実音へ加え、Playキーを保つ。コード、メロディ、階名の主音も一緒に移調する。カポ0→6/7/11は+6/+7/+11半音として扱い、最短距離の-6/-5/-1へ折り返さない。カポを下げる操作も逆方向の正確な音程を使う。

原曲キーを手動で選ぶと、その時点の実音キーを変更する。その後にカポを動かすと、その時点のPlayキーを保って実音が動く。「実音を保つ」では実音コード/メロディを変えず、カポからPlayキーを逆算する。両モードを切り替えた場合も適用まではProjectへ書かない。

キー・カポ画面に、変更前/変更後の原曲キー（実音）、Playキー、カポを並べて表示する。登録フォームの自動更新、単一Undo、明示Saveの契約は維持する。キャンセルでProject/履歴は無変更。Session切替・未確定入力・IME・保存/競合時の既存ガードを通す。

実装上は操作要求に任意のtransposeSemitonesを加えた。整数・±24半音以内・指定キーとの一致を検証し、欠落時は従来のキー間最短移調を維持する。保存schemaやProjectへこの引数は追加しない。
