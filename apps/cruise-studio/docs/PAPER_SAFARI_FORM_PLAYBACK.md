# Safariのフォーム中央配置・小節単位の再生表示 — 0.125.0-dev.1

## Safari実機で確認した原因

利用者の開いていたSafariのローカル18874、保存済みの合成テストProjectで確認した。0.124候補はフォームのspan外枠の高さ34.13pxに対し、実際のSVG画像は29.69pxだった。外枠のaspect-ratioと画像の縦横比の計算差により、外枠を中央にしても白背景が上に寄っていた。旧候補の上余白4.09px/下余白7.89pxを実測した。

強制aspect-ratioとSVGのheight:100%を外し、SVG自身の縦横比で外枠の高さが決まるようにした。実譜面と表示設定の見本へ同じ修正を適用。Safariで外枠/画像とも29.69px、上余白6.48px/下余白5.50pxを確認（上辺罫線約0.87pxを除いた内側差は約0.11px）。前回のlane基準修正は維持する。

## 再生と選択

- 紙面の小節へフォーカスがある時もSpaceで曲を再生/停止できる。選択小節から曲末まで、未選択なら先頭から。セクション選択の開始位置指定も維持する。
- 曲再生のSpace/メインボタン停止では、停止直前の音声時計から小節を求めて選択し、編集カードは閉じたままにする。自然終了では最後に再生した小節を選択する。
- 通常の編集/小節移動/Project切替等で止める場合は、この停止位置の選択を抑止し、新しい操作先を上書きしない。
- メインボタンは「再生」「停止」のみ。準備中はaria-busyで伝える。
- 紙面の行ごとの移動帯を廃止し、現在の小節全体を選択と同じ青色で表示する。再生中は元の選択枠とフォーカス枠を隠し、小節ごとに即時切替。棒だけ音声時計に沿って滑らかに動く。
- 編集カード内のセル帯/音符の表示、入力中のSpace・IME・リピート防止は既存の所有範囲を維持する。Project/履歴への書込みはない。
