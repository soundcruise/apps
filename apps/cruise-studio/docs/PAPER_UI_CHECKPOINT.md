# 譜面UI・再生 — 0.114.0-dev.1

2026-11-12。0.113.0-dev.1（45fc8f49）からの独立したローカル候補。対象は譜面クルーズのみ。

## 動作

- 「コード進行を再生」は、編集中の1／2小節のコード×ストロークを既存の再生投影で鳴らす。登録フォームの弦・フレット・チューニング・カポを優先し、メロディは鳴らさない。上下方向、ミュート、休符、伸ばしを維持する。
- このボタンでは、ストロークの空欄に限り、各拍の表（0/480/960/1440tick）とコードの入力位置でダウンを補う。明示した休符・伸ばしの区間へ補わない。これは試聴投影だけで、Projectやストローク素材へ書き戻さない。未入力コードを別の和音へ置き換えない。
- 再生中のハイライトを、マス幅の帯が再生位置に沿って滑らかに動く表示へ変更。「再生」「メロディ」「コード進行」「全曲」に適用し、対象外の行へ帯を出さない。停止・別小節・別Projectへの移動で消去し、印刷に含めない。
- 譜面上の各コード位置へ登録フォームを表示できる。安定したコードevent ID→binding→素材IDからのみ取得し、未登録コードの自動生成・採用はしない。原本の白黒SVG描画を再利用し、ダイアグラム内のコード名は省略。同時位置の複数フォームは重ねず縦に配置する。
- 上部カードへ「コード／フォーム／ストローク／歌詞／ドレミ」のチェックを集約。既存4項目は既存の保存設定・Undo/Redoを維持。「フォーム」は初期OFFのSession内表示状態で、Project/JSONの項目を増やさない。再読込み後は再度ONにする。
- フォームがあるセクションでは、歌詞なしでも設定した小節数で改行し、フォームだけが過密な小節数へ詰め込まれないようにする。画面拡大・印刷にもSVGを使用する。
