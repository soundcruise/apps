# 表示設定全体のプリセット・行揃え — 0.121.0-dev.1

## 変更内容

- 最下部の通常UIは「プリセットを選択」と「新規保存」。新規保存を押すと名前入力と登録が開く。同名は上書きせず拒否し、登録後は入力欄を閉じる。
- 新規プリセットは文字サイズ9種類（アーティスト名を追加）、フォームサイズ、全体の1行小節数、小節番号/セクション名の表示、現在のProjectの行ごとの枠数/小節数を保存する。選択で下書きへ呼び出し、上部の保存で確定する。キャンセル/Escでは登録・削除・呼出しも取り消す。
- 既存の8種類の文字サイズプリセットは「文字サイズのみ」と表示して維持する。呼出しでフォームサイズ、行配置、アーティスト名サイズは上書きしない。
- スライダーを曲名、アーティスト名、曲情報、セクション名、小節番号、コード、フォーム、ストローク、歌詞、ドレミの順に変更。アーティスト名は初期16px、10〜26pxで調整でき、見本の対応箇所も強調する。
- フォームの必要段数を全曲一律から小節ごとの計算へ変更。後半の密なフォームで前半まで余白が増える問題を修正。横一列の高さだけを共有し、単独の図は中央に配置する。
- 譜面の横一列で番号/コード/フォーム/ストローク/歌詞/ドレミの各トラックをCSS subgridで共有。入力の有無や文字サイズによらず上下位置を揃える。表示中の項目は空欄でも行を保持し、チェックを外した項目だけ隠す。見本と実譜面は同じ描画を使う。

## 保存互換性

表示設定は従来のscorePaperDisplayV2へ1回の書込みで確定する。新規プリセットはtype=display-settings-v1とlayout、rowsを持つ。rowsは小節番号/枠数/使用小節数の配置レシピで、元Project IDや小節IDを保存しない。別Projectへ呼び出す際はそのProjectの小節IDへ対応させ、存在しない番号は無視する。小節や音の追加・削除・無効化は行わず、他Projectの行指定も保持する。

旧表示キー/旧プリセットを保持し、保存失敗・別画面競合・キャンセル時の保護を継続。譜面上部のProject保存対象の表示チェックを、新しくプリセットへ移す変更はしていない。今回の全体保存は表示設定画面の調整項目と、ローカルの番号/セクション名表示を対象とする。Project schema、素材、音楽データ、Undo/Redo、Repository、Account/Sync、公開HTML/配信設定、正式版0.88.1は変更しない。
