# 譜面の表示・ズーム・ストローク位置のローカル検証

2026年11月20日。譜面クルーズのローカル候補 `0.203.0-dev.1`。実装と回帰テストは `98b61a738`、`72ddbe1d1`、`8fd142ce6`、`290e22749` に収録した。

## 表示と操作

- 「今日からの歌」を1行4小節で確認した。コード14px、ストローク15px、歌詞12px、ドレミ11px、歌詞とドレミの字間−1px。ローカルSafariにこの組み合わせを「デフォルト」として登録した。表示設定の初期化でフォームとフォーム一覧も非表示に戻る。
- コード・歌詞・ドレミの配置を各行の入力マスに合わせた。「ファ」は「フ」の右下に小さい「ァ」を置く。拍ごとに分割を変えた場合も、小節編集画面と譜面の各行の境界が一致することをテストした。
- 譜面の余白を含むピンチとControl／⌘＋ホイール、ズームボタンの上下限25～400%を確認した。小節線を薄くし、選択枠を1pxにした。再生中の第5小節は、ローカル検証の画面サイズではツールバーと再生操作部の間の上から約31%の位置に表示された。
- ストロークは音価にかかわらず開始位置から同じだけ内側に記号を置く。第16小節の全音符は1拍目、第24小節の2分音符は1・3拍目に配置されることをmacOS Safariで確認した。ChromeとWebKitで全音符から16分音符、付点2分音符を含む実曲の譜面・印刷表示・書き出したビューワーを計測し、想定位置との差は最大0.52 CSS px以内だった。

## ピアノ音源の照合

編集画面の鍵盤で中央のド（C4）を入力し、譜面を再生してからビューワーに書き出して再生した。それぞれの再生開始時にWeb Audioに渡されたデコード済みサンプルを全チャンネル取得し、SHA-256と再生レートを比較した。

| ブラウザー | 3経路すべてで得たPCMのSHA-256 | サンプルレート | フレーム数 | 再生レート |
| --- | --- | ---: | ---: | ---: |
| Chrome | `1e9bb660de9394d91bb91f71d11285ea95d5e65ad39d97b38ad535e184069f6e` | 48 kHz | 776,691 | 1 |
| WebKit | `c4e0c764638cc501bb52279c67a69ec53290479a48fccb91ae5306be2a8a0084` | 48 kHz | 776,691 | 1 |

両ブラウザーで、それぞれ鍵盤・譜面・ビューワーの3経路が一致した。音源はSalamander Grand Piano（Yamaha C5）。鍵盤の単音試聴は1.6秒、譜面では音符の長さとミックス音量が適用される。
