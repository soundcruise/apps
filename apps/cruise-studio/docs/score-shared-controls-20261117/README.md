承認された機能差は維持する。譜面クルーズは**停止**、Viewerは**一時停止して続きから再開**。複数選択時は譜面クルーズが反復を自動ON、Viewerは反復ボタンの指定に従い、両方でON/OFFを明示する。再生中の練習BPM変更は、譜面クルーズが**現在の小節の頭から再開**、Viewerはその場で変速する。

## 共用と境界

`score-ui.mjs`で下部バー、音モード、反復アイコン、全画面、設定の余白を共用する。詳細表示は`paper-layout.mjs`を共用し、Viewerでは独立したメモリ上の表示所有者を使う。Viewerに編集Sessionや書き込み権限を渡さず、元譜面をreadOnlyで描画する。Viewerのプリセットに含まれるズーム・横配置も往復させる。取消は変更前へ戻す。

表示設定の試聴は独立した音声所有者を使い、Viewerの通常の閲覧位置・範囲と譜面クルーズの選択・履歴を変更しない。停止時にContextを解放し、遅い音源読込・再操作・全停止の世代検証で再生復活を防ぐ。

譜面クルーズの練習BPMは`scorePracticeBpmV1`としてブラウザ内に保存する。不正な既存設定を無条件に上書きしない。テンポ再開用の開始オフセットは発音時計だけに適用し、コード・メロディの音程や音源再生速度を変えない。再生中のメトロノーム切替は独立ゲートと次拍の予約に反映し、カウントインや曲の発音を消さない。無効な拍ガイドを遅延音楽イベントと誤判定して停止する回帰も修正した。

正式Studio0.88.1、譜面形式v1、プリセットv1、ライブラリDB v3は変更しない。
