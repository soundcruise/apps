# コードフォーム入力・本棚JSONのローカル確認

候補0.109.0-dev.1。入口：http://127.0.0.1:18874/

未保存内容を保存してから再読込する。旧版でも開きたいProjectは、新しいフォームを登録する前にJSONを書き出して残す。旧Projectはそのまま読めるが、新版フォームを保存した後は未対応の旧版では開けない。

## コードとフォーム

1. テスト用Projectで小節を開き、コードのマスへCなどを入力する。コードとおすすめフォームが同じUndo単位で登録される。
2. コード欄の▼を押すと、選択中のフォームを小さな白黒図で表示する。横の7個のダイアトニックから直接入力できる。
3. 「詳細設定」でカラー指板・任意コード・CAGEDを使う。CAGEDの型はクリックすると直接反映される。別の採用ボタンは置かない。
4. カラー指板の位置・指をクリックして編集する。操作説明は指板見出しの「？」を開く。ダイアトニックや任意コードを明示選択すると、以前の固定フォームもそのコードの候補へ切り替わる。コード名とフォームは1回のUndoで戻せる。直接文字入力で既存の固定フォームを保持する動作は維持する。未確認の演奏条件・構成音を、確認済みとは扱わない。
5. 自動フォームはコード名変更に追従する。固定フォームは通常の文字編集では元の形を保持し、不一致を要確認にする。一覧／任意コードの明示選択は、コードとフォームの変更を表す。元に戻す／やり直すを試し、残す編集を「保存」する。

新規Projectは標準6弦・22F。既存で条件不明のProjectは最初の自動登録前に確認する。キャンセルすると元のデータを維持し、未確定入力のまま移動しない。既存の確定条件は上書きしない。

## 同じ画面の本棚から選ぶ

1. 18874で入力先のコードのマスを選び、「詳細設定」→「コード本棚を開く」を押す。ここでは別タブを開かず、同じ画面の本棚パネルを展開する。右窓へ移した編集カードでも使える。
2. 初回はパネルの「読取り専用ブックマークを登録」から「本棚から譜面へ（読取り専用）」をブックマークバーへドラッグして登録する。以前のブックマークは登録し直す。
3. フォームも必要なら「フォームも取り込み・採用する」を確認して選び、「本棚を取り込む／更新」を押す。この初回読取りだけProの別タブを使う。ポップアップが拒否されたら許可して再度押す。
4. Proの通常認証は利用者が行い、本棚を開いて登録したブックマークを実行する。コードにチェックを付ける。「表示中のコードをすべて選択」やフォルダ選択も使える。「譜面の本棚へ取り込む」を押す。
5. 18874の本棚パネルに一覧が現れる。取込みだけではProjectや履歴を変更しない。Proタブは閉じてよい。
6. この画面でフォルダを選び、コード名のボタンを押すと、選択中の譜面のマスへ入力される。「フォームも取り込み・採用する」が選ばれていれば固定フォームを同時採用する。別のマスを選んでも同じ本棚を使える。1回のUndoで入力を戻せる。保存は通常の「保存」で行う。

コピーはSessionごとのメモリ内だけにあり、別Projectと混ざらず、再読込で消える。入力して保存したコード・フォームは通常のProjectに残る。本棚のコピーを永続保存する新しい方式は作らない。

認証や別originの保存を共有しない。補助は本棚の索引・フォルダ・明示選択されたレコードだけを読み、本棚のレコード・順序・設定・資格情報には書き込まない。Window間のpostMessageは送信元origin、開いたタブそのもの、都度の識別子、形式・容量を照合する。カタログ取込みだけが複数件を許可し、旧1マス入力の1件制限は緩めない。最大256KiB・512件。Project全体や資格情報をProへ送らない。取込み待ち中に入力先・Project・条件が変わると接続を破棄し、10分で期限切れになる。fetch/API/Cloudは使わず、18874のconnect-src noneを維持する。

実Proのブラウザ分離ヘッダー等で連携できない場合はJSONを予備に使う。本番設定を緩めない。実Pro／実Safariの操作はHOLD。

## JSONの予備経路

18874の取込みと接続していないPro単体の本棚で同じブックマークを実行すると、従来のJSON書出し画面になる。フォルダとコードを選び、名前のみ／フォーム付きの書出しボタンを押す。通常のPro入口は https://soundcruise.jp/apps/chord-cruise/pro_k7m4q9v2x8/ 。

単一の6弦フォームにできない未確定状態や、ベース／テンションの個別指定を含むレコードは、フォーム送信・書出しを拒否する。名前のみは利用できる。

## 譜面へ取り込む

1. 18874で入力先のコードのマスを選び、「詳細設定」の「JSONファイルから読み込む（予備）」でファイルを選ぶ。読み込んだだけでは譜面は変わらない。
2. 名前だけならそのまま一覧から選ぶ。フォーム付きなら「フォームも固定して取り込む」の確認欄を選んでから一覧でコードを選ぶ。元のIDとフォルダで同名コードを区別する。
3. 元本棚にない楽器条件を、確認なしに補完しない。確認欄は元フォームをカポ0・標準6弦とし、Projectのフレット上限（不明なら22）と押さえ方を確認するもの。Projectの条件と一致しなければ入力全体を拒否する。
4. 名前と固定フォームは1回のUndoで戻る。保存・再読込・JSON再出力を確認する。取込み一覧は再読込で消えるが、入力して保存したコードとフォームは通常のProjectに残る。

名前専用JSON v1は維持。フォーム付きは別format/versionで、256KiB／512件を上限に余分な項目・重複ID・不正な弦やフレットを拒否する。
