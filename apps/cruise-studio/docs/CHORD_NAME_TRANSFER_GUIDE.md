# コードクルーズ本棚 → 譜面のコード入力

候補 0.105.0-dev.1。ローカル入口: http://127.0.0.1:18874/

## 一度だけの登録

1. ローカルで未保存のProjectを保存してからページを再読込する。
2. 譜面の小節を開き、コードのマスを選ぶ。ラベル右の「−」の下の「▼」でコード画面を開く。
3. 「コードクルーズ」ボタンを押し、「コード本棚から入力」の「本棚からJSONを書き出す」を開く。
4. 「本棚のコード名をJSON書出し」を、Safariのお気に入りバー／Chromeのブックマークバーへドラッグして登録する。これは、表示中のコードクルーズ本棚を読取り専用で扱うブックマークで、ローカル画面上でクリックしても本棚を読み取らない。

## 本棚から書き出す

1. いつものコードクルーズProを通常の認証で開き、「コード本棚」を表示する。
   リポジトリで確認した入口は https://soundcruise.jp/apps/chord-cruise/pro_k7m4q9v2x8/ 。Studio内に埋め込まれた画面ではなく、Pro単体のタブで使う。
2. 登録した「本棚のコード名をJSON書出し」ブックマークを押す。
3. フォルダで絞り込み、譜面に渡すコードへチェックを入れる。複数選択できる。
4. 「選択したコード名をJSON書き出し」を押し、`chord-names.json`を保存する。本棚のレコード・順番・設定は変更しない。フォーム、メモ、認証情報、Syncバックアップは書き出さない。

## 譜面へ入力する

1. 18874へ戻り、コード画面の「コードクルーズ」を開き、「コード名JSONを読み込む」でファイルを選ぶ。
2. 入力先のコードのマスを確認し、一覧でコードを選択する。同名でも、フォルダ名と元のIDで区別する。選択すると、その拍のコード欄へ直接入力される。ファイルを読み込んだだけではProjectを変更しない。
3. 間違えた場合は「元に戻す」で1回の選択を戻せる。「やり直す」も使える。
4. 残したい編集はStudioの「保存」で保存する。再読込すると取込み一覧は消えるが、入力して保存したコードは通常のProjectに残る。別Projectで使う場合も同じJSONを読み込める。

コードとして解釈できない独自名は自動変換せず、元のマスを保持して案内を表示する。必要に応じて元UIの任意コード作成から入力する。フォームのスナップショットや任意に編集した指使いの取込みは、このJSONの対象外。

## 分離と確認範囲

- 書出し補助は選択した本棚のキーだけを読む。認証画面が表示中、または本棚を開いていない時は拒否する。認証API・資格情報を利用せず、通信・保存領域への書込みを行わない。
- ローカル側は既存の127.0.0.1:18874専用入口・CSP connect-src noneを維持する。コードクルーズの元UI／CSS／指板レンダラーを隔離DOMで再利用し、設定はメモリ内だけに保持する。元アプリのlocalStorageへ接続しない。
- 転送形式はコード名専用v1。上限256KiB／512件、名前64文字。重複ID・不明な版・余分なフォーム等の項目・壊れたJSONを拒否する。拒否時は前の一覧とProjectを保持する。
- 合成した本棚からの実ダウンロード→取込み→入力→Undo、元UIとの指板・スタイル比較、保存再読込・JSONをChrome／WebKitで検証する。実ユーザーの本棚は試験に使わない。
- 実Safariと実際のPro本棚でのブックマーク登録・書出しは利用者確認待ち（HOLD）。本番公開やPro認証の実機検証を完了した扱いにはしない。

起動中のサーバーは継続利用する。停止している場合の起動コマンドは、今回のworktreeで `python3 apps/cruise-studio/scripts/serve-local-ui.py`。原本UIのローカル生成物は入口の生成時に自動更新され、公開パッケージには含めない。
