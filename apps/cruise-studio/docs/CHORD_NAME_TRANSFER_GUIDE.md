# コードフォーム入力・本棚JSONのローカル確認

候補0.107.0-dev.1。入口：http://127.0.0.1:18874/

未保存内容を保存してから再読込する。旧版でも開きたいProjectは、新しいフォームを登録する前にJSONを書き出して残す。旧Projectはそのまま読めるが、新版フォームを保存した後は未対応の旧版では開けない。

## コードとフォーム

1. テスト用Projectで小節を開き、コードのマスへCなどを入力する。コードとおすすめフォームが同じUndo単位で登録される。
2. コード欄の▼を押すと、選択中のフォームを小さな白黒図で表示する。横の7個のダイアトニックから直接入力できる。
3. 「詳細設定」でカラー指板・任意コード・CAGEDを使う。CAGEDを選んだだけでは保存フォームは変わらない。「このフォームを採用」で表示中の形を固定登録する。
4. カラー指板の空いた位置をクリックすると、その弦の押さえる位置を変更する。運指表示で指をクリックすると、コードクルーズと同じ順で指指定・注意・削除を切り替える。×をクリックすると開放弦になる。各変更は既存のSessionのUndo/Redoへ入る。変更した押さえ方は未確認として保持し、確認できた時だけ確認欄を選んで採用する。構成音の不足は確認欄だけでは解消しない。
5. 自動フォームはコード名変更に追従する。固定フォームは元の形を保持し、不一致を要確認にする。元に戻す／やり直すを試し、残す編集を「保存」する。

新規Projectは標準6弦・22F。既存で条件不明のProjectは最初の自動登録前に確認する。キャンセルすると元のデータを維持し、未確定入力のまま移動しない。既存の確定条件は上書きしない。

## 本棚のページから直接選ぶ（推奨）

1. 18874の入力先コードのマスを選び、「詳細設定」→「コード本棚から入力」→「読取り専用ブックマークを登録」を開く。
2. 「本棚から譜面へ（読取り専用）」をブックマークバーへドラッグして登録する。以前のJSON書出し用ブックマークは登録し直す。
3. フォームも必要なら「フォームも固定して取り込む」を確認して選び、「コード本棚を開く」を押す。別タブで通常のコードクルーズProが開く。ポップアップが拒否されたら許可して再度押す。
4. Proの通常認証は利用者が行い、アプリ内で本棚を開く。登録したブックマークを実行する。右下に読取り専用の選択補助が現れる。
5. 元の本棚のコード図を1件クリックし、補助の「コード名を譜面へ入力」または「名前とフォームを譜面へ入力」を押す。入力は1回のUndoで戻せる。保存は18874の「保存」から行う。

認証や別originの保存を共有しない。補助は本棚の索引・フォルダ・選択した1件のレコードだけを読む。本棚のレコード・順序・設定・資格情報には書き込まない。Window間のpostMessageは送信元origin、開いたタブそのもの、都度の識別子、形式・容量・1件制限を照合する。Project全体や資格情報をProへ送らない。入力先のマス・Project・条件が変わると接続を破棄する。10分で期限切れ。fetch/API/Cloudは使わず、18874のconnect-src noneを維持する。

実際のPro側のブラウザ分離ヘッダー等で連携できない場合は、下のJSONを予備に使う。本番設定を緩めない。実Pro／実Safariでの操作はHOLD。

## JSONの予備経路

18874から開かずに、Pro単体の本棚で同じブックマークを実行すると、従来のJSON書出し画面になる。フォルダとコードを選び、名前のみ／フォーム付きの書出しボタンを押す。通常のPro入口は https://soundcruise.jp/apps/chord-cruise/pro_k7m4q9v2x8/ 。

単一の6弦フォームにできない未確定状態や、ベース／テンションの個別指定を含むレコードは、フォーム送信・書出しを拒否する。名前のみは利用できる。

## 譜面へ取り込む

1. 18874で入力先のコードのマスを選び、「詳細設定」の「JSONファイルから読み込む（予備）」でファイルを選ぶ。読み込んだだけでは譜面は変わらない。
2. 名前だけならそのまま一覧から選ぶ。フォーム付きなら「フォームも固定して取り込む」の確認欄を選んでから一覧でコードを選ぶ。元のIDとフォルダで同名コードを区別する。
3. 元本棚にない楽器条件を、確認なしに補完しない。確認欄は元フォームをカポ0・標準6弦とし、Projectのフレット上限（不明なら22）と押さえ方を確認するもの。Projectの条件と一致しなければ入力全体を拒否する。
4. 名前と固定フォームは1回のUndoで戻る。保存・再読込・JSON再出力を確認する。取込み一覧は再読込で消えるが、入力して保存したコードとフォームは通常のProjectに残る。

名前専用JSON v1は維持。フォーム付きは別format/versionで、256KiB／512件を上限に余分な項目・重複ID・不正な弦やフレットを拒否する。
