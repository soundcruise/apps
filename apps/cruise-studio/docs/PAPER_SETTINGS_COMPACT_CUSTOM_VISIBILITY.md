# 表示設定の整理と紙面ヘッダーの表示切替 — 0.122.0-dev.1

## UI

- 最下部のプリセットを、見本をまたぐ全幅から左側の設定列へ移動。通常は選択と新規保存の2操作。名前入力中も列内に収める。おすすめボタンと状態文も左側へ置き、狭い列で不自然に文字が折れないようにする。
- 行ごとの枠数/使用小節数は、初期状態で閉じた「カスタム設定」へ格納。「行の個別設定を…」の説明は削除。見本で行をクリックした場合は該当行のカスタム設定を開く。
- ユーザー画像の数値を初期値に採用：1行4小節、フォーム110%、曲名26px、アーティスト名16px、曲情報11px、セクション名13px、小節番号9px、コード16px、ストローク15px、歌詞14px、ドレミ12px。
- 保存済み設定は勝手に書き換えず、「おすすめに戻す」で新しい初期値を試せる。保存/キャンセルの下書き処理を維持する。
- 上部の表示チェックを、曲名→アーティスト名→曲情報→セクション名→小節番号→コード→フォーム→ストローク→歌詞→ドレミの順へ変更。新しい3項目はローカル表示設定として保存し、表示プリセットにも含める。
- 曲名を隠してアーティスト名だけ表示した場合は先頭の区切り記号を隠す。ヘッダーの全項目を隠すと空のヘッダーも消す。実譜面・見本・印刷に同じ表示設定を適用する。

## 互換性と検証

旧設定にない表示フラグはtrueで補完。既存Project、Music Model、素材、Undo/Redo、Repositoryの保存契約、旧プリセットを維持する。実Account/Sync、本番認証、共有CSS、公開HTML/配信設定、正式版0.88.1への変更はない。

関連Node400件、Chrome119件/WebKit119件、実18874＋模擬本棚18件PASS、skipなし。外部/本番認証/Cloud通信0、page errorなし。

新しい初期値、表示チェック順、個別の非表示/再表示、ヘッダー余白、見本/印刷への適用、再読込み、プリセット保存/呼出し、Project/履歴不変を検証。左列のプリセットは通常/名前入力の双方を1440px/390pxで検査。行カスタムの初期非表示と、見本クリックで対象行を開く操作も確認済み。従来の編集操作試験は明示的な2小節/100%の配置を使い、新しい初期値は専用試験と実入口で検証する。

既存の高速ストローク初回クリック断続未反映、OS印刷・聴感、実アカウント本棚接続などのHOLDは継承する。
