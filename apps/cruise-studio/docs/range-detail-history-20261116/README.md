# ローカル候補 0.140.0-dev.1 — 範囲再生・フォーム詳細・履歴プレビュー・曲情報表示

基準: `7f69b433` / `codex/score-toolbar-ui`。先行の未commit差分を保持。正式バージョンは0.88.1のまま。ローカル入口: http://127.0.0.1:18874/ 。本番配信、公開HTML、Account/Sync、他アプリ、sharedは変更しない。commit / pushなし。

## 操作

- 複数小節を選んで再生すると、選択した全小節の青い背景・枠を保持し、現在地の棒だけが滑らかに移動する。通常の単一開始位置からの再生は従来の小節ハイライトを維持する。
- コード詳細は「指板 / CAGED」→説明→「コード名 / ▶ コードを再生」→指板→表示モードの順。上部の白黒フォームを252pxから196pxへ縮小。C/A/G/E/Dを明示的に選ぶとSession再描画後に実際のフォームを表示する。通常の指変更は元の横・縦スクロールを保持する。
- 白黒フォームの押さえた位置をクリックすると、詳細指板と同じ指サイクルで変更する。開放弦からミュート、ミュートから開放弦にも変更できる。書込みは既存Session/adopt経由、最少1音・素材の不変性・Undo/Redo・保存/JSONを維持する。譜面上のフォーム拡大とは別の操作。
- 「履歴」はタイトル部をドラッグして移動。Alt＋矢印キーでも移動できる。履歴の選択で譜面だけを表示し、Project / Session / Undoカーソル / dirty / 保存済み内容を変更しない。「キャンセル」、Escape、カード外クリックで現在の譜面へ戻る。プレビュー中は元の編集カードを一時的に隠し、取消時に元の選択を保持する。
- 「決定」後に、失われる後続履歴の件数と、やり直し不可・保存前は保存済み曲を変えないことを表示。「この時点に戻す」を改めて押した時だけ復元し、その後の履歴を破棄する。通常のUndo/Redoは引き続き後続履歴を保持する。IME / キーリピート / ダブルクリック / 古いSession ticket / 外部更新 / 保存中を保護する。
- 表示設定の「曲情報」→「さらに詳細」で、ORGキー / Playキー / カポ / BPM / 拍子 / 基本ストロークを個別に表示ON/OFF・書体・色・サイズ調整できる。未指定は親の曲情報設定を継承。個別設定は親より優先し、「個別設定をリセット」で継承へ戻る。保存/取消・完全な表示プリセット・再読み込み・印刷CSSへ反映する。ブラウザ内設定のみで、曲JSON / クラウド同期には含めない。

## 検証

- 新しい専用ブラウザ試験: Chrome / WebKit。実際のloopback UI、使い捨てストレージ、合成Project、外部通信遮断。
- 範囲の計算済み背景・影・番号色が小節移動/ループ前後で同じ。棒は1本、拍別の帯はなし。Project/履歴は不変。
- CAGED全5形と低位置へ戻す操作、通常指変更時の位置保持、390/1024/1440px、白黒/カラー双方の指変更・ミュート・Undo/Save/reload。
- 履歴のドラッグ、プレビュー不変性、警告前後の取消、確認後の後続履歴破棄、古い確認の拒否、短い過去譜面から取消して新しい小節選択を維持。
- 曲情報の親子色の優先、個別書体/サイズ/非表示、取消/保存/プリセット/reload、印刷メディア。
- 全Node試験、既存の譜面UI、範囲選択、Save As、再生ミキサー、メトロノーム、カウントイン、スクロール追従も回帰確認。実行数はverification.jsonを参照。
- WebKitはSafari実機そのものの確認ではない。既存ユーザーのSafari・保存領域・実アカウントには触れていない。OS印刷ダイアログ・実スピーカー聴感は今回の確認対象外。

画像は専用試験の合成データ。`compact-detail-*.png` は高さ1800pxで編集カード全体を表示した例。`meta-details-*.png` は個別の書体・色・サイズとカポ非表示を試した状態。`history-preview-*.png` は履歴の警告を表示中の例。
