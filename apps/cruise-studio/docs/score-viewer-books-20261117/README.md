## 操作

- 同名書き出しは静的な曲名と「別名で書き出す／上書きする／キャンセル」だけを表示する。「別名で書き出す」を青い主操作と「おすすめ」で示し、選んだ後に名前入力へ進む。戻る／取消、Enter、重複名・空名の拒否を維持。同名が複数ある場合だけ、上書きする本とファイルを明示選択する。保存は従来の項目ID・versionによるCASを維持。
- ライブラリはコード本棚と同じ、本の表紙・背・棚板の構成。指定なしの項目は仮想の「未分類」に表示し、既存DBと原本bytesを移し替えない。本を開くと曲一覧、編集を押した時だけ名称／格納先・複製・削除・本の管理を表示。既存の入れ子・削除確認・独立した複製を保持する。
- 上部は独立した「ライブラリ」と「メニュー」。メニューにPCからファイルを開く・送り設定・音設定・PDFで書き出すを集約。PDFは送り設定とPDF書き出しを備え、音設定は表示しない。
- 下部の再生は常に中央。BPMと選択表示を左、Repeatと音モードを右へ置き、狭い画面では音モードを次の行へ送る。集中表示でも再生・Repeat・音モードを使える。
- 保存済みの場合は保存ボタンを非表示にし、保存通知だけ短時間表示する。未保存の保存ボタンとファイル変更・離脱時の確認は維持する。
- 送り設定は自動スクロールのON/OFF、BPM／カスタム、速度へ整理。説明は「?」に入れる。OFFでも音・演奏時計は進む。設定は端末・ファイルの版ごとに保存し、独自譜面・PDFとも再読込後に復元する。
- 旧「自動追従に戻る」は手動スクロール後に演奏位置へ戻す操作だった。突然下部へ現れる表示を廃止し、送り設定の中で必要な時だけ「スクロール再開」を表示する。

| 選択 | Repeat OFF | Repeat ON |
| --- | --- | --- |
| なし | 全曲 | 全曲を反復 |
| 1小節 | そこから曲末まで | その小節を反復 |
| 複数小節 | 選択範囲で停止 | 選択範囲を反復 |

選択の青いハイライトは再生中も保持する。曲時計・カウントイン・先行発音予約・原本BPM・音高を別々に変更しない。

## 再生位置と描画

音声予約は従来どおりAudioContext.currentTimeで行う。表示には出力装置へ届いた時刻を使い、対応環境の `getOutputTimestamp()` を performance.now() に対応付ける。未対応時は公表されたbaseLatency／outputLatencyで補正する。過去のテンポ・範囲・ループ世代を短い有界履歴に保持し、出力の遅れがテンポ変更・小節末・周回をまたいでも正しい位置を求める。停止／seek／context解放では履歴を切り替える。固定の手動オフセットや別の曲時計は導入していない。[Web Audio仕様](https://webaudio.github.io/web-audio-api/#dom-audiocontext-getoutputtimestamp)。

棒は拡縮された小節・subgridの中から外し、紙面直下の1要素を合成レイヤーとしてtranslate3dで移動する。小節の位置・寸法は再レイアウト時だけ計測する。余計な棒を生成せず、停止・再描画で解除する。スクロールも表示用時刻に合わせる。音楽内容やAudioNodeの予約を遅延させる方法は採らない。

PDF回帰でWebKitのResizeObserver警告を確認。空・非表示のreaderを監視し続ける経路を整理し、表示中でファイルを持つreaderだけ監視する。離脱時は切断し、再表示で再接続する。警告をフィルターして試験を通す処理は加えていない。

## 確認した範囲

Chrome／WebKitの自動試験と、開かれていたSafariのローカルStudioで確認。Safariでは本棚→未分類の3曲、再生・Space停止・1小節反復、反復解除後の曲末までの再生を確認した。反復中と停止後の画面に残像の縦線は見られなかった。音が出ていることはSafariの状態でも確認できるが、人間による聴感の同期評価やBluetooth機器ごとの遅延実測とは区別する。スマホは画面寸法・タッチ相当試験であり、物理端末の実機検証ではない。
