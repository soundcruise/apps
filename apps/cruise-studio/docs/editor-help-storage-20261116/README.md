## 表示設定の保存先

表示設定の上部（保存ボタン付近）と、ページ下のプリセット欄に、保存先がこのブラウザであり、曲JSONやクラウド同期には含まれないことを明示。「保存」「新規保存」には対応する説明をaria-describedbyで関連付ける。

保存先、AppSettingキー、保存/取消のトランザクション、プリセットの形式は変更しない。レイアウト・文字・表示ON/OFFは既存のブラウザ設定であり、曲そのものの保存と区別する。ヘッダーはスマホで折り返し、プリセットは左側の最下部を維持する。

## 編集カードの「？」

1小節/2小節の浮動カード・右窓共通のヘッダーに「？」を配置。読み取り専用の「編集の操作ガイド」をnative dialogで開く。次の4項目で操作を案内する。

- 再生とSpace: 譜面、編集カードの余白、ストロークのマス、文字入力中の違い。
- マスと小節の移動: Enter、Tab/Shift+Tab、左右、上下。ドレミ内の音選択と、小節末/曲末の扱い。
- ストローク入力: 上下とD/U、Shift+上下による行移動、休符、ミュート、伸ばし、空欄への消去。
- 保存・元に戻す・終了: Ctrl/Command+S/Z、Shiftでやり直し、Escape、日本語変換中の優先順位。

Enter/Spaceで「？」を起動できる。ヘルプはTab/Shift+Tabを内部で循環し、Space・矢印・Enter・保存/Undoのキーを譜面へ伝えない。Backspace/Deleteによるブラウザ遷移も防ぐ。Escape/閉じるでヘルプだけを閉じ、元の入力欄または「？」へフォーカスを戻す。入力中の値・カーソル位置・小節選択・曲内容・Undo項目を保つ。通常のフォーカス移動に伴う既存のテキストグループ確定は変更しない。

不正な入力が残っていてもヘルプは読め、閉じると入力を修正できる。日本語変換中はヘルプへフォーカスを移さない。再生中に開くと再生を止め、自動では再開しない。画面離脱・Project切替では閉じ、古い入力へフォーカスを戻さない。読込待ちの間に編集カードを閉じた場合は、遅れてヘルプが開かない。印刷には表示しない。

## ローカル確認

`http://127.0.0.1:18874/` を再読み込みする。

1. 「表示設定」を開き、上部と下部のプリセット欄の保存先説明を確認。
