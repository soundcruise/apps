# テンション候補による開放弦欠落のローカル修正

2026-11-12。開発候補 1.23.1-dev.1。正式版 1.23.0 と公開HTMLのcache identityは変更せず、公開・配布しない。

Cadd9のC型は1弦0FのEを含むが、1弦10FのDがテンション候補として重なると、描画モデルが「同じ弦の確定した押弦音」と扱って0Fを消していた。3弦の開放表示も同じ原因で消える。保存データやCAGEDの元フォームから消えていたわけではない。

Exploreだけが preserveOpenTensionCandidates を指定し、isOverlay と isTensionCandidate が両方ある候補は、元の開放表示を消さない。実際に選ばれた押弦・通常の競合・オプション未指定の挙動は維持する。保存形式・同期・認証は変更しない。

原本の競合判定試験と、譜面側の合成ブラウザから読み込んだ原本Explore／ローカル編集面の双方で、Cadd9の開放弦と候補表示を検証する。本番サイトの実機で修正済みとは扱わない。
