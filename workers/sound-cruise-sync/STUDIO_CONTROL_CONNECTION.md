# Maintenance control connection candidate

The new host-side privateCurrentReader requires an explicit service binding. It only exposes observe(OPEN), sends a signed nonce-bound CURRENT request through the existing private gateway, verifies the Control receipt, and never authorizes freeze. No public URL, listener, fallback, Control command, or automatic remote binding session is installed. A Wrangler remote-binding proxy may itself create remote development-session resources, so it must not run without the specific session authorization.

connectCurrentFloor connects the PR87 maintenance guard to the immutable commit/head/expected-head-CAS transport contract previously tested for Latest Pin. GitHub commit OIDs remain 40 characters in the backend. The protocol head is a 64-character digest of backend identity plus commit, so it cannot be confused with a bundle hash or a raw commit. Whole linear ancestry, genesis, external minimum commit/sequence, event uniqueness, cumulative grant history, Source/Owner and current window/epoch are validated. Retirement cannot be reversed; a subsequent window requires a new operation/window and epoch+1. A changed head during observation is INCONCLUSIVE. No observation is called an atomic snapshot.

The floor signer has its own explicit public key, normalized Ed25519 JWK fingerprint and authority. The fingerprint must match the authorized issuer pin and differ from the Control issuer. Control CURRENT cannot serve as independent floor storage. Live backend qualification and external minimum witness remain separate approvals; testOnly fixtures cannot be promoted to Production. A signed callback alone is not independent durability. Administrator/signer compromise, rollback below an unmaintained external floor, and unauthorized changes to backend protections are outside the qualified fixture guarantee.

The concrete test transport reuses the existing disposable bare-Git CAS fixture. No GitHub credential or real pin branch is used. The operational GitHub App transport remains limited to its old approved purpose; it is not silently widened to freeze-floor refs. A future live adapter must demonstrate repo/branch protection, qualified writer, explicit expectedHeadOid, independent readback and monotonic external floor before receiving a live qualification grant.

Final CAS follows PR87's durable intent claim. A lost ACK is UNKNOWN and cannot resend on the same transport. Cross-process intent recovery is the existing PR87 runner responsibility, not proved by opening a new adapter alone. Historical chain reads and process-reopen reads do not renew authorization. Source data is never rolled back by a floor transition.

Actual Control is currently unconfigured: no FREEZE_CONFIG, no Product admission, no Source D1/R2 binding. Current initialization would create Control DO state. Public variables/configuration, remote service sessions and initialization are not applied by this candidate. A configuration hash is not an operator approval, and an unsigned deployment-certificate candidate is not evidence that the instrumented Product artifact has been deployed.

Production stays NORMAL v138. Host grant remains unsigned. Fresh Target metadata is consistent with the last unused reservation but cannot prove the absence of all intervening third-party actions. Old broad Lab management access must be resolved before real data transfer. No Source rows/object list/body, Backup, Restore, freeze, cron or Product deployment is performed.
